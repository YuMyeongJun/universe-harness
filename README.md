# qa-automation

정책에서 테스트 케이스(TC)를 만들고, 그 TC 로 테스트를 자동화한다.

```
정책(스펙·기획·정책서) ──▶ TC ──▶ 자동 테스트 ──▶ 결과
```

이 저장소는 2026-09-10 에 비워지고 다시 시작했다. 이전 것(프론트엔드 에이전트 훈련장 「우주」)은
가지 `archive/universe-2026-09-10` 과 태그 `universe-last` 에 그대로 있다.

## 이어받는 것

- **셋으로 말한다.** 통과 · 위반 · **못 쟀다**. 「0건」은 「위반 없음」이 아니라 「아무것도 안 봤다」일 수 있다.
- **자기 채점을 막는다.** TC 를 쓴 손과 테스트를 쓴 손이 같으면 채점이 아니다.
- **초록불은 증거가 아니다.** 검사를 넣었으면 일부러 깨서 무는지 본다.
- **수치는 손으로 적지 않는다.** 잰 것만 적고, 전달받은 값은 원문을 대조하기 전엔 안 옮긴다.
