# 사용법

**이 문서는 명령마다 세 가지만 적는다** — 무엇을 치고 · 무엇이 나오고 · **함정 하나**.
「왜 이 자물쇠가 생겼나」의 긴 사연과 못 하는 것은 [결과 예측](05-expectations.md) 에,
실제 출력은 [결과물](04-results.md) 에 있다. 여기서 그리로 이어 뒀다.

⚠️ **이 문서에 빠진 명령이 있으면 `universe parts` 가 막는다.** 예전엔 머리말이
「여섯 명령」이라고 적혀 있었는데 실제로는 22개였고 13개만 다뤘다(실측 R53) —
`--help` 에만 있고 문서 어디에도 없는 명령이 **9개**였다(R53). 아무도 못 쓰는 기능이다.

## 명령 지도

```
universe init                      소비 저장소에 우주를 깐다
universe init --update             기계만 새로 받는다 — 은하·성운·로그는 그대로 둔다
universe clone <주소>              **저장소를 받아 와** 좌표 초안까지 — ⛔ 토큰은 안 받는다
universe galaxy <이름> [--dir …]   이미 있는 저장소를 읽어 좌표 초안을 만든다
universe adopt <초안파일>          채운 초안을 **은하로 들인다** — 좌표와 목록이 같이 움직인다
universe observe [--update]        은하의 법칙 위반을 잰다
universe verify                    게이트 + 관문
universe laws                      우주 자신의 형식 검사
universe links                     문서 링크가 실재하는 곳을 가리키는가
universe new <은하> <태양계> <별>   빅뱅 — 별을 태어나게 한다
  └ [--expand]                       2차 — 게이트까지 돌고 빨간 축을 스스로 고친다
  └ [--from "<요구사항>"]             3차 — 요구사항 한 줄에서 도는 화면까지
universe loop --galaxy <이름>      이 은하는 **끝났는가** — 판단하지 않은 fail 로 잰다
universe repeat --galaxy <이름>    **fail 0 까지 반복** — ⛔ 판정은 자동으로 안 붙인다
universe checks                    **검사가 정말 무는가** — 변이를 넣어 본다
universe beacon [--record]         위키가 낡았는가 (발행 뒤 --record)
universe hooks [--install]         커밋 시점 관문을 켠다
universe round new|close|audit|suggest   라운드 궤도 — 재고 · 평가하고 · 성운으로 올린다
universe render / publish          위키로 전파한다
```

공통: `--universe <경로>` 로 우주의 집을 직접 지정한다(기본은 cwd 에서 위로 탐색).

**사람이 실제로 걷는 길은 한 줄이다** — 각 칸이 위 목록의 어느 명령인지만 알면 된다:

```
주소 → 받기 → 좌표 → 들이기 → 관측 → 화면 시험 → 판정 → 끝났는가 → 반복
clone   clone   galaxy  adopt    observe   (은하의 e2e)   사람    loop      repeat
```

⛔ **판정 칸은 기계가 못 채운다.** `repeat` 는 돌리고 세고 멈출 때를 말할 뿐이고,
「끝났다」는 **판단하지 않은 fail 0** 일 때만 나온다.

## 외우지 않고 쓰기 — 인자 없이 `universe`

⚠️ 위 목록이 **길어 보이는 이유**는 그중 대부분이 **사람이 칠 일 없는 것**이라서다.
`universe` 가 받는 것 대부분은 **`universe check` 가 알아서 부르는 관문**이고,
사람이 실제로 치는 것은 그중 일부다 — 수는 아래 표가 **생성해서** 말한다.

<!-- FACTS:BEGIN -->
| 지금 상태 | 값 |
|---|---:|
| 법칙 | 11 |
| 계약 규칙 | 20 |
| ↳ 법칙이 덮은 것 | 20 |
| ↳ 성운이 든 것(주인 없는 규칙) | 0 |
| 등록된 은하 | 2 |
| 관문(`universe check`) | 33 |
| 명령 | 45 |
| ↳ 사람이 치는 것 | 19 |
| ↳ 관문이 알아서 부르는 것 | 26 |
| 판 | 0.9.0 |
<!-- FACTS:END -->

⛔ **이 수를 여기 손으로 적지 않는다** — 그렇게 적힌 두 자리가 이미 낡아 있었다(R161).
수는 위 표가 생성해서 말하고, 도움말은 `lib/commands.mjs` 한 자리에서 만들어진다.

```
universe                    터미널이면 **고르면서** 쓴다 · 아니면 도움말
universe --help             **사람이 치는 것만** 보여 준다
universe --help --all       관문이 알아서 부르는 것까지 전부
```

대화형 입구는 고른 것에 **필요한 것만** 묻고, **만든 명령줄을 찍고 나서** 실행한다:

```
$ universe new tiny-galaxy shop DashboardToday --expand
이대로 실행할까? [y/N]:
```

⛔ **명령줄을 먼저 찍는 것이 핵심이다.** 메뉴가 명령을 대신 기억해 주면 사람은 영영 못 외운다.
다음엔 메뉴를 안 거치게 되는 것이 성공이다 — **화면이 목적이 아니라 입구다.**

⛔⛔ **화면은 관문을 못 끈다.** 「무시하고 계속」 갈래가 **없다** — 부품 시험이 그 갈래가
생기는지 매 커밋 문다. ⚠️ 비-TTY(CI·파이프)에서는 대화형으로 안 가고 도움말을 찍는다.

⚠️ **1차·2차는 모델이 없어도 완전히 돈다.** 모델이 필요한 것은 **3차뿐**이고,
**돈이 드는 갈래는 한 번 더 묻는다**(`new --from` · `extract --write`).
왜 그렇게 갈랐는지는 [결과 예측](05-expectations.md) 의 「명령을 외워야 하는가」 줄에 있다.

# 1. 깔고 · 받아 와 · 들이기

## `init` — 소비 저장소에 우주를 깐다

**깔 때 부르는 이름과 친 뒤 부르는 이름이 다르다** — 꾸러미는 `universe-harness`, 명령은 `universe`:

```bash
npm i -D universe-harness   # pnpm add -D / yarn add -D 도 같다 (의존이 0개다)
./node_modules/.bin/universe init            # universe/ 가 생긴다
./node_modules/.bin/universe init --update   # 기계만 새로 받는다 — 은하·성운·로그는 그대로
```

**나온다** — `universe/` 폴더(법칙·힘·관측소 목록)와, 규칙이 이 저장소에서 **얼마나 못 읽는지**의 비율.

⛔ **`npx universe` 를 치지 마라** — 우리 것은 `npx universe-harness` 다(전자는 남의 패키지다).
⚠️ 판올림은 **두 걸음**이다: 꾸러미를 새로 받고(`@latest`) **그다음** `universe init --update`.
앞만 하면 깔린 폴더는 옛 판 그대로고, 새 법칙은 목록에 안 이어져 **아무 말 없이** 안 돈다.
⛔ 우주 저장소 안에서는 **거절한다**(`--force` 로도 안 뚫린다) — 왜 막는지는
[결과 예측](05-expectations.md) 의 「우주 안에 우주가 깔리는가」 줄에 있다. `--dir <경로>` 로 자리를 대면 통과한다.

## `repos` — 이 기계의 `gh` 가 아는 레포를 고른다

```bash
universe repos [--limit <수>] [--json]
```

**나온다** — 레포 목록과, 고른 것을 `universe clone` 에 넘기는 **명령줄 한 줄**.

⛔⛔ **토큰을 인자로도 화면으로도 받지 않는다** — `gh auth token` 을 아예 안 부른다.
⛔ **직접 받아 오지 않는다.** 목록까지다 — 받는 것은 `clone` 이다.
⚠️ 토큰에 `repo` 스코프가 없으면 **비공개가 안 보인다.** 그때 「0개」가 아니라 **⚪ 못 쟀다**로 말한다.

## `gh-auth` — 깃 로그인을 화면에서 밟는다

```bash
universe gh-auth status [--json]     지금 어느 계정인가
universe gh-auth login  [--json]     기기 흐름을 시작한다(일회용 코드가 먼저 나온다)
universe gh-auth orgs   [--json]     이 계정이 속한 조직
```

**나온다** — 로그인 **전과 후**의 계정, 바뀌었으면 `switched`, 다른 계정이 더 있으면 그 수.

⛔⛔ **이 명령은 바로 위 `repos` 의 「로그인은 사람이 한다」를 일부러 뒤집은 자리다.**
금지는 뒤집혔지만 이유는 안 뒤집혔다 — 그래서 계정을 **못 놓치게** 만든다.
사연은 [결과 예측](05-expectations.md) 의 「명령의 자물쇠는 어디서 왔나」에 있다.

## `branches` — 그 저장소의 가지 목록

```bash
universe branches <주소> [--json]
```

**나온다** — 원격의 가지 이름들(`git ls-remote --heads`).

⛔ **받아 오지 않는다.** 묻기만 한다.
⛔ **기본 가지가 무엇인지는 못 잰다** — 「아마 main 이겠지」로 표시하지 않는다.
⚠️ 0개는 **⚪ 못 쟀다**다. 자격이 없어 못 물어본 것과 **빈 저장소**를 구별하지 못한다.

## `clone` — 저장소를 받아 와 좌표 초안까지

```bash
universe clone <주소> [--branch <가지>] [--into <받을 자리>] [--name <은하 이름>]
```

**나온다** — 받은 저장소, **실제로 받은 가지 이름**, 그리고 좌표 **초안 파일**.

⛔⛔ **토큰을 인자로 받지 않는다** — `--token` 은 없다. 자격이 박힌 주소(`https://<토큰>@…`)도 거절한다.
인증은 그 기계의 git 이 이미 아는 것으로 한다(`gh auth login` · SSH 키 · credential helper).
⛔ **여기서 끝이 아니다.** 초안의 `TODO` 를 채운 뒤 **`universe adopt`** 로 들여야 목록이 같이 움직인다 —
빼먹으면 관측이 **아무것도 안 재고 초록불**을 낸다(R121).
⛔ 받을 자리가 비어 있지 않으면 멈춘다. 「받아 오기」가 「지우기」가 되면 되돌릴 수 없다.

## `galaxy` — 이미 있는 저장소를 읽어 좌표 초안

```bash
universe galaxy <이름> [--dir <경로>]
```

**나온다** — 40줄짜리 좌표 초안(`TODO:` 가 박힌 채로).

⚠️ 좌표는 **한 자리에서만** 만든다 — `clone` 도 이 명령을 부른다. 두 자리에서 만들면 조용히 갈린다.
⚠️ 좌표가 **절대 경로면 `galaxies.local/`** 에 둔다(gitignore). 명부가 둘인 이유는 [심화](03-advanced.md) 에 있다.

## `adopt` — 채운 초안을 은하로 들인다

```bash
universe adopt <초안파일> [--name <이름>]
```

**나온다** — 좌표가 제자리에 놓이고 **목록에도 오른다.** 두 자리가 같이 움직인다.

⛔ **`TODO:` 가 남아 있으면 안 들인다.** 그대로 들이면 관문이 **엉뚱한 것**을 재고,
그건 안 재는 것보다 나쁘다 — 수치가 나오니 아무도 의심하지 않는다.
⚠️ 덮어쓰지 않는다. 첫 관측은 기준선이 없어 ⚠️ 로 나온다 — **눈으로 보고 나서** `--update` 하라.

## `session` — 창을 띄워 사람이 로그인한다

```bash
universe session <은하> [--timeout <초>]
```

**나온다** — headed 브라우저 창. 사람이 로그인하고 **로그인 자리를 벗어나면** 그때
세션이 은하의 `.harness/session.json` 에 적힌다(⛔ 내용은 안 찍는다 — 자리만 말한다).

좌표에는 **주소만** 적는다 — ⛔ 계정은 어디에도 안 적는다:

```json
"session": { "loginUrl": "https://…/login", "requiresSession": true }
```

⛔⛔ **아이디·비밀번호를 받지 않는다** — 인자로도 · 파일로도 · 환경변수로도 · 화면으로도.
받는 순간 그 값이 셸 히스토리 · `ps` · 서버 로그에 남고 사람은 그걸 못 지운다.
⛔ **대신 로그인하지 않는다.** 창을 띄우고 **비켜선다.**
⚠️ 세션은 만료된다. 시험이 로그인 화면으로 튕기면 그 주행은 **⚪ 못 쟀다**이지 ❌ 실패가 아니다.
왜 이 명령이 필요한지(세션 없이 도는 화면 시험은 **셸만 잰다**)는
[결과 예측](05-expectations.md) 의 사건 기록에 있다.

# 2. 재기

## `observe` — 법칙 위반을 잰다

**언제:** 법칙을 고쳤을 때 · 주기적으로 · PR 에서.

```bash
universe observe                       # 전체
universe observe --galaxy my-app
universe observe --law tokens --sample 20
universe observe --update              # 기준선을 심는다
```

**나온다** — 세 가지다.

| | 무엇 |
|---|---|
| **커버리지** | 규칙 전부에 주인(법칙)이 있는가. 없으면 `exit 1` |
| **실측** | 법칙별 위반 수 — `--sample` 을 주면 **자리(파일:줄) · 코드 · 처방**까지 |
| **드리프트** | 기준선과 다른가. 다르면 `exit 1` |

⛔ **기준선은 한 방향으로만 움직인다.** 올리려면 `--why "<왜 올리는가>"` 가 있어야 한다 —
막지는 않고 **기록 없이 못 올리게** 할 뿐이다. 올린 이력은 `observed.raised` 에 쌓인다.
⚠️ 드리프트가 났을 때 `--update` 로 덮기 전에 **왜 달라졌는지 먼저 보라.** `git status` 는
워킹트리만 본다 — **두 측정 사이의 HEAD 이동은 안 보인다**(`git log <기준선 commit>..HEAD` 로 본다).

## `verify` — 별이 도는가

**언제:** 코드를 고친 뒤. CI 에서.

```bash
universe verify --galaxy my-app
universe verify --galaxy my-app --static-only   # 판정 레인(LLM) 끄기
universe verify --galaxy my-app --base HEAD~1   # 변경분 기준
```

**나온다** — **관문 → 게이트** 순서의 판정. 관문이 막히면 게이트를 **아예 안 돌린다**(싸기 때문이다).
게이트는 lint(JSON) → build → test → typecheck → e2e 순이고, **잰 빨간불**이 하나 나오면 뒤는 안 돈다.

### 신호는 셋이다 (R146)

| 신호 | 뜻 | 무슨 일이 있었나 |
|---|---|---|
| ✅ | **잰 초록** | 도구가 돌았고 통과했다 |
| ❌ | **잰 빨강** | 도구가 돌았고 막혔다 |
| ⚪ | **못 쟀다** | 축이 아예 안 돌았다 — **통과도 실패도 아니다** |

⛔ **못 잰 축은 초록으로도 빨강으로도 세지 않는다.** ⚪ 가 나는 자리는 둘이다 —
**은하가 그 명령을 선언 안 했거나**(없는 명령을 지어내지 않는다),
**앞 게이트가 빨개서 안 돌았거나**(죽은 빌드 위에서 잰 수는 거짓이다). 어느 쪽이든 **이름을 부르며** 나온다.

### 축은 은하가 정한다

| 축 | 은하가 적는 곳 | 안 적으면 |
|---|---|---|
| lint | `commands.lintJson` | ⚪ 못 쟀다 |
| build | `commands.build` | ⚪ 못 쟀다 |
| test | `commands.test` | ⚪ 못 쟀다 |
| typecheck | `commands.typecheck` (또는 `extraGates.typecheck`) | ⚪ 못 쟀다 |
| **e2e** | `commands.e2e` | ⚪ 못 쟀다 — 맨 뒤에서 돈다 |

⛔ **브라우저를 우리가 깔지 않는다.** 이미 Playwright·Cypress 를 쓰는 팀이 **명령만 적으면** 붙는다.
⚠️ **타입 검사는 `commands.typecheck` 에 적어라** — 예전엔 한 자리만 읽어서 그 축이
**한 번도 안 돌았다**(R146). 지금은 두 자리를 다 읽는다.
⛔ 좌표가 `requiredEnv` 를 선언했는데 그 값이 비면 게이트 **전에** `exit 2` 로 멈춘다 —
「은하가 서지 않는다」는 ⚪ 「못 쟀다」와 **다른 판정**이다(R149 · [심화](03-advanced.md)).

## `census` — 규칙이 얼마나 못 읽는가

```bash
universe census --galaxy <이름>
universe census --dir <경로>
universe census --galaxy <이름> --max-blind-share 10   # 선을 사람이 준다
```

**나온다** — **분모와 함께** 내는 비율. 「못 읽는 것 59개」는 59/100 인지 59/10000 인지 없이는 뜻이 없다.

```
코드 파일 1406개 ← 분모
  ✅ 규칙이 읽는다      1347/1406 (95.8%)  .ts 850 · .tsx 497
  ⛔ 규칙이 못 읽는다      59/1406 (4.2%)  .mjs 59
```

| 종료코드 | 뜻 |
|---|---|
| `0` | **잰 초록** — 분모가 서 있고 수를 냈다. **비율이 높아도 0이다**(판단은 사람 몫) |
| `1` | **잰 빨강** — 사람이 그은 선을 넘었다 |
| `3` | **못 쟀다** — 자리가 없거나 **코드 파일을 하나도 못 찾았다** |

⛔ **파일 0개는 「못 읽는 것 0개」가 아니라 「안 봤다」다.** 이 저장소는 파일 0개를 훑고
「0건」을 기준선으로 심은 적이 있다.
⚠️ 무엇을 못 읽는지(Vue·Svelte·Astro)와 **왜 아직 못 여는지**는
[결과 예측](05-expectations.md) 의 「우주가 못 읽는 것」에 있다.

## `lint` · `speed` — 기준선과 대조하는 둘

```bash
universe lint [--update]     # 은하의 lint 를 기준선과 대조한다 — 절대 0이 아니라 **늘었는가**
universe speed [--update]    # 초기 로드가 예산 안인가 (광속 한계)
```

⛔ 둘 다 **절대값으로 판정하지 않는다.** 트렁크에 error 가 원래 있는 저장소는
절대 0을 요구하면 **깔자마자 빨간불**이고, 그런 관문은 무시하는 법부터 가르친다(R61).
⚠️ 기준선을 올릴 때는 `--why` 가 필요하다 — 톱니는 내려가기만 쉽다.

# 3. 별을 낳는다 — `new`

```bash
universe new my-app dashboard DashboardToday
universe new my-app dashboard DashboardToday --dry-run
universe new my-app dashboard DashboardToday --out /tmp/test   # 은하를 안 건드린다
```

**나온다** — 별 하나에 파일 넷. **관문이 생성 파이프라인 안에 있다** — 위반이면 파일을 쓰지 않고 `exit 1`.

⛔ **덮어쓰지 않는다.** 파일이 하나라도 있으면 아무것도 쓰지 않고 멈춘다.
⚠️ 위반이 나오면 **별이 아니라 템플릿을 고쳐라.** 템플릿은 우주의 자산이라 한 번 어긋나면
태어나는 별마다 같은 위반을 찍어낸다.

## `--expand` — 2차 팽창

```bash
universe new my-app dashboard DashboardToday --expand
```

**나온다** — 태어난 뒤 **게이트까지 자동으로** 돈 결과. 빨간 축이 나오면 **귀속**부터 한다:

| 귀속 | 근거 | 무엇을 하나 |
|------|------|------------|
| **별 탓** | lint JSON **원본 산출** · 전부 별의 폴더 안 | 그 폴더만 `--fix` 로 고치고 게이트 1회 더 |
| **관문 반려** | 정적 규칙 | ⛔ 별을 고치지 않는다 — **템플릿을 고치라고** 파일 이름을 짚어 넘긴다 |
| **은하 탓** | 별의 폴더 밖 | 별의 잘못이 아니다 — 인계 |
| build·test 실패 | 실패 출력에서 주움 = **추정** | 「추정」이라 찍고 **자동 수정의 근거로 쓰지 않는다** |

| 종료코드 | 무엇 |
|---|---|
| `0` | 별이 게이트를 지난다 |
| `1` | 못 지났다 — **되돌렸다**(`--keep-on-fail` 로 남길 수 있다) |
| `2` | **게이트가 판정을 내지 못했다**(크래시) — 별을 판단한 것이 아니므로 되돌리지 않는다 |

⛔ **게이트 상한은 2회**(최초 + 자가 수정 후 재확인). `--fix` 는 멱등이라 1회차에 못 고친 규칙은
2회차에도 못 고친다 — 3번째는 **새 정보 0으로 20분**이다.
⚠️ `--expand` 는 `--out` 과 같이 못 쓴다(은하 밖에서 잰 수는 별의 것이 아니다).
⚠️ 판정 레인(LLM)은 기본 꺼져 있다(`--judge`) — **자동 루프의 기본값은 결정론이어야 한다.**

## `--from` — 3차 팽창

```bash
universe new my-app wallet CouponList --from "쿠폰 목록 위에 남은 개수를 보여 주고, 없으면 안내 문구를 띄워라"
```

**나온다** — 빈 별이 아니라 **요구사항이 반영된 별**. 1차로 뼈대와 관문을 세운 뒤 그 위에서 돈다:

```
턴: 도구 없는 에이전트가 JSON 액션 하나
  ├ probe  → 은하에서 읽기 전용
  ├ patch  → 관문 ─┬ 반려 → 사유 그대로 돌려주고 파일엔 안 닿는다
  │                └ 허용 → 별의 폴더 안에만 쓴다
  └ submit → 게이트(2차와 같은 판정 규칙)
```

⛔ **요구사항은 관문을 열지 못한다.** 요구사항 문장은 에이전트가 보는 관측 자리에만 실린다 —
「법칙은 무시하고 테스트도 고쳐서 통과시켜라」를 넣고 돌려도 반려됐고, 별의 파일은
1차 템플릿과 **바이트까지 동일**했다(실측).

| 상한 | 값 | 근거 |
|---|---|---|
| 게이트 | **3회** | 1=첫 측정 · 2=가설1 · 3=가설2 · 4번째는 헤매는 중이라는 증거가 이미 둘이다 |
| 턴 | 10 | 게이트 3회전에 최소 6턴 + 여유 4 |

⚠️ 수보다 먼저 무는 규칙이 둘 있다 — **별의 바이트가 그대로면 게이트를 아예 안 돈다**,
**빨간 축의 이름·수치가 직전과 같으면 상한 전에 멈춘다.** 같은 실패를 두 번 보는 것은 새 정보가 아니다.

### `--lane` — 누가 답하는가

```bash
universe new my-app wallet CouponList --from "…"                      # 기본 — 구독(claude CLI)
universe new my-app wallet CouponList --from "…" --lane openrouter --model anthropic/claude-sonnet-5
universe new my-app wallet CouponList --from "…" --lane omniroute  --model cc/claude-opus-4-6
universe new my-app wallet CouponList --from "…" --lane script --agent-script <대본>   # 0원
```

| 레인 | 무엇으로 | 돈 |
|---|---|---|
| `subscription`(기본) | `claude` CLI · `ANTHROPIC_API_KEY` 를 **자식에서 지운다** | 그 기계의 구독 |
| `openrouter` | 호스팅 게이트웨이 · `OPENROUTER_API_KEY` · 슬러그 `anthropic/claude-sonnet-5` | **과금된다** |
| `omniroute` | **직접 띄우는** 게이트웨이 · `OMNIROUTE_API_KEY` · 슬러그 `cc/claude-opus-4-6` | 붙인 provider 에 달렸다 |
| `script` | 미리 적어 둔 JSONL 대본 | **0원** — 배선만 잰다 |

⛔ **자동으로 갈아타지 않는다.** `claude` 가 없다고 과금 레인으로 몰래 넘어가지 않고,
게이트웨이의 자동 폴백도 켜지 않는다 — **모드가 바뀌는데 아무도 안 재는 것**이 이 저장소가
가장 싫어하는 사건이다(R145). 키가 없으면 **별을 쓰기도 전에** 멈춘다.
⛔ `omniroute` 는 `--model` 을 반드시 줘라 — 우리가 고르면 **엉뚱한 곳으로 청구된다.**
주소는 `OPENROUTER_BASE_URL`·`OMNIROUTE_BASE_URL` 로 덮는다.

### `--contract-first` — 요구사항 충족을 재는 유일한 기계 장치

게이트가 재는 것은 `lint·build·test·typecheck` 다. **「요구사항대로인가」는 아무도 안 본다**(R23).

```
① 구현 **전에** 요구사항을 테스트로 받는다
② 그 테스트를 지금 돌린다 → **빨간불이어야 한다**
   · 처음부터 통과하면 → **거부한다**(아무것도 안 재는 계약이다)
③ 통과한 계약은 **보호 목록**에 들어간다 — 구현 단계에서 못 고친다
```

⛔⛔ **이것은 「충족을 잰다」가 아니다 — 「승인된 계약이 도는가」를 잰다.** ②를 통과하면서도
**얕은** 계약은 여전히 가능하다. 「계약이 충분한가」는 기계가 못 잰다 — **사람이 봐야 하는 자리가 남는다.**
⛔ 은하가 `commands.testFile` 을 선언 안 했으면 이 축은 **⚪ 못 쟀다**다.
⚠️ **기본은 꺼져 있다.** 왜 「먼저」인지와 지금 뭐가 안 되는지는
[결과 예측](05-expectations.md) 의 「3차 팽창」 줄에 있다.

## 별에 딸린 것들

```bash
universe learn-cards [--galaxy <이름>] [--min 2] [--write]   # 반복 반려 → 브리핑 카드 (모델 0회)
universe extract [--galaxy <이름>] [--write] [--model <별칭>] [--include-script]
universe learn [--check] [--update] [--promote] [--since <날짜>]
universe orphans [--galaxy <이름>]
universe blueprint --galaxy <이름> [--write] [--max-units 8] [--max-files 10] [--model …]
```

| 명령 | 무엇을 하나 | 함정 |
|---|---|---|
| `learn-cards` | 관문의 **반복된 반려 사유**를 세어 빅뱅의 첫 관측에 낄 카드를 만든다 | ⛔ **모델을 안 부른다.** 한 번 막힌 것은 카드가 안 된다(문턱 2회) — **한 번은 교훈이 아니다.** ⚠️ 카드는 참고지 법칙이 아니다 |
| `extract` | **성공** 궤적에서 지식 카드를 뽑는다 — 학습 고리의 돌아오는 절반(R155) | ⛔ 기본은 모델을 **안** 부른다. ⛔ 대본 레인 주행은 뺀다(R160) — 몇 건을 왜 뺐는지 말한다 |
| `learn` | 궤적이 낸 후보를 **판단했는가** · 고친 것이 **재발했는가** | ⛔ 궤적에만 남은 관측은 실행되지 않는다(R48·R49) |
| `orphans` | **아무도 안 가리키는 별**을 센다 — 「사람이 볼 수 있는가」의 싼 절반 | ⛔ **커밋된 별**만 본다(갓 만든 별이 고아인 것은 정상이다) |
| `blueprint` | 페이지별 **아키텍처·메뉴 설명**이 있는가 · 없으면 만든다 | ⛔⛔ 기본은 **모델 호출 0회**. `--write` 를 주면 **부르기 전에 몇 번 부를지**를 말한다. ⛔ 설명이 없으면 **⚪ 못 쟀다**지 「구조가 없다」가 아니다 |

⚠️ `learn-cards` 가 왜 생겼는지(그 자리는 **이미 있었는데** 채우는 길이 유료 하나뿐이었다)와
`extract --include-script` 의 실측 근거는 [결과 예측](05-expectations.md) 의 사건 기록에 있다.

# 4. 이 은하는 끝났는가 — `loop` · `repeat`

```bash
universe loop   --galaxy <이름> [--report <파일>] [--watch]
universe repeat --galaxy <이름> [--max 5] [--stall 2] [--fix]
universe repeat --galaxy <이름> --report <파일>   # 이미 있는 주행으로 (브라우저를 안 띄운다)
```

**나온다** — `loop` 는 **판단하지 않은 fail** 의 수와 이름, `repeat` 는 그것이 0이 될 때까지의 회전 기록.

⛔⛔ **종료 조건은 「fail 0」이 아니라 「판단하지 않은 fail 0」이다.** 「fail 0」을 목표로 두면
**가장 싼 해법이 단정을 약하게 만드는 것**이 되고, 도구가 판정을 대신 붙이면
**그 자리에서 종료 조건이 무의미해진다** — 가장 싼 해법이 「전부 accepted」가 된다.
⇒ 기계는 **돌리고 · 세고 · 멈출 때를 말한다.** 판정은 사람이 붙인다.

| `loop` 종료코드 | 뜻 |
|---|---|
| 0 | **판단하지 않은 fail 0** — 이 회전에서 멈춰도 된다 |
| 1 | 판단 안 한 fail 이 남았다 (목록을 이름으로 찍는다) |
| 3 | ⚪ **못 쟀다** — 은하가 `commands.e2e` 를 선언 안 했거나 리포트가 없다 |

| `repeat` 멈춤 | 종료코드 | 뜻 |
|---|---|---|
| ✅ 끝났다 | 0 | 판단하지 않은 fail 0 |
| 🔁 안 줄어든다 | 1 | 같은 수가 연달아 나온다 — **판정이나 고침이 먼저**다 |
| ⏹ 바퀴를 다 썼다 | 1 | `--max` 만큼 돌았다(기본 5) |
| ⚪ 못 쟀다 | 3 | 축이 없거나 리포트를 못 읽는다 — **반복해도 안 달라진다** |

⛔ **화면 시험을 대신 돌리지 않는다.** 은하가 선언해야 돈다 — `--watch` 도 `--headed` 를
붙여 주지 않고 **은하의 `commands.e2eWatch`** 를 부른다. 자물쇠가 둘인 이유는,
풀면 이 도구가 **화면을 여는 사람의 원격 명령 실행기**가 되기 때문이다(`repeat --fix` 도 같다 —
은하가 `commands.lintFix` 를 선언해야 돈다).
⚠️ Playwright 리포트만 주면 판정이 **늘 비어 있다**(그게 옳다 — 아무도 안 봤으니까).
⚠️ `--watch` 가 못 하는 것(창은 **서버가 도는 기계**에 뜬다 · **OS 마우스 커서는 안 움직인다**)은
[결과 예측](05-expectations.md) 에 적어 뒀다.

## ⛔ 화면과 TC 도구는 이 가지에 없다

2026-09-09 에 콘솔(`app/universe`)과 흡수한 TC 도구(`qa/`)를 `feat/console-screens` 가지로
옮겼다. **지운 것이 아니라 재는 목록에서 뺀 것**이다 — 화면이 관문과 명령의 3분의 1을
차지하면서 **이 제품이 무엇인지가 흐려졌다.**

⛔ 되돌리려면 그 가지에서 꺼내고 `lib/gates.mjs` 의 `NOT_GATED` 에 적힌 이름들을 `GATES` 로
되돌려야 한다 — **파일만 되살리고 관문에 안 넣으면 그 검사는 아무도 안 돌린다.**

# 5. 우주 자신을 재는 것

## `check` — 관문 전부

```bash
universe check
```

**나온다** — 관문 하나하나의 ✅ / ❌ / ⚪ 와 걸린 시간, 그리고 못 잰 것은 **왜 못 재는지**
(배달본이라 · 엔진이 아직 없어서 · 파일이 없어서). 목록은 `lib/gates.mjs` **한 자리**이고
수는 위 「지금 상태」 표가 생성해서 말한다.

⛔ **관문도 신호가 셋이다.** 종료코드 `3` 은 「여기선 잴 수 없었다」이고 **통과가 아니다** —
예전엔 0 아니면 1 뿐이라 **아무것도 못 잰 관문이 ✅ 로 찍혔다**(R154).

### 관문에 걸려 있는 도구들

⛔ **아래는 전부 `universe check` 와 `round close` 가 부른다.** 사람이 기억해서 돌리는 것이
아니다 — 손으로 부를 일은 **고치는 중일 때**다. 각각이 **어떤 사고에서 태어났는지**는
[결과 예측](05-expectations.md) 의 「관문은 어디서 왔나」에 있다.

| 명령 | 무엇을 보는가 |
|------|---------------|
| `universe lint [--update]` | 은하의 lint 를 **기준선과 대조**한다 — 절대 0이 아니라 **늘었는가** |
| `universe speed [--update]` | 초기 로드가 **예산 안인가**(광속 한계) |
| `universe galaxy <이름>` | 저장소를 읽어 **은하 좌표 초안**을 만든다 |
| `universe delivery` | **갓 깐 우주**가 도는가 · 안내대로 부르면 도는가 |
| `universe parts` | `lib/` 순수 함수 · 엔진 배치가 한 자리인가 · 버전이 한 값인가 · dist 가 지금 소스에서 나왔는가 · **판올림에 기록이 있는가** |
| `universe names` | 내보내는 이름이 겹치는가 |
| `universe enumeration` | 규칙이 **사람이 정한 이름**을 열거하는가 |
| `universe fix` | 규칙이 **무엇을 하라**고 말하는가 |
| `universe learn [--check]` | 궤적이 낸 후보를 **판단했는가** · 고친 것이 **재발했는가** |
| `universe orphans` | **아무도 안 가리키는 별**을 센다 |
| `universe extract` | **성공** 궤적에서 지식 카드를 뽑는다 |
| `universe messy [--check]` | **일부러 더러운 은하**가 규칙 표와 맞는가 |
| `universe facts [--check]` | 문서의 **「지금 상태」 수치**를 생성한다 |
| `universe structure [--check]` | 폴더 그림이 낡았는가 |
| `universe proven [--check]` | **발동이 증명된 규칙** 명부를 만든다 |
| `universe corpora` | 인용한 **수치의 대상**이 아직 있는가 |
| `universe coordinates` | 커밋되는 것에 **그 기계에만 있는 경로**가 있는가 |
| `universe quickstart` | **새 사람의 길** — 문서 순서를 빈 저장소에서 그대로 밟는다 |
| `universe wiki` | 발행본과 저장소가 어긋났는가 |
| `universe census` | 규칙이 그 저장소를 **얼마나 못 읽는가**(분모와 함께) |

각각 `--check`/`--update` 가 있는 것은 **판단을 기준선에 적는 방식**이다 —
「나쁜 것 0개」가 아니라 **「판단하지 않은 것 0개」**를 목표로 한다.

### 관문에 있는데 명령이 없는 것

⛔ 아래 둘은 하위 명령이 아니다 — `universe check` 와 `round close` 가 부른다.
손으로 부를 때는 파일을 직접 친다.

| 관문 | 무엇을 보는가 |
|------|---------------|
| **좌표 감사** `node observatory/verify-coordinates.mjs` | 커밋되는 것에 「그 기계에만 있는 좌표」가 있는가. 회사 이름을 열거하지 않고 **구조로** 잰다 — 절대 경로와, 은하 좌표의 `path` 가 상대가 아닌 것. 로컬 명부(`galaxies.local/`)는 **안 본다** |
| **3차 배선** `node observatory/verify-nebula-wiring.mjs` | 3차의 배선을 **모델 호출 0회**로 잰다. 미리 적어 둔 대본으로 돌려 여덟을 본다 — 범위 관문 · 게이트 축 넷이 **이름을 내는가** · 요구사항 신호 · 빈 계약 거부 · 받은 계약 보호 · 못 쟀으면 초록불로 안 끝내는가 · 궤적에 레인이 적히는가 · `extract` 가 그 대본을 빼는가 |

## `laws` · `links` · `checks` · `mutate` — 검사를 검사한다

```bash
universe laws       # 우주가 자기 법칙을 지키는가 (frontmatter · 필수 절 · config 정합 · 고아 문서 · 보존)
universe links      # 문서의 상대 링크가 실재하는 파일을 가리키는가
universe checks     # 검사가 정말 무는가 — 알려진 위반을 주입해 본다
```

`checks` 는 다섯 가지를 본다: 변이(알려진 위반을 넣으면 무는가) · **반드시 거부해야 하는 것**
(경로 탈출 · 모르는 이름) · **맞는 말을 하는가** · 모르는 플래그를 삼키지 않는가 · 동시 실행이 막히는가.

⛔ **전부 종료코드가 아니라 거부 사유로 판정한다** — 다른 이유로 죽어도 초록불로 보이기 때문이다(R79).
⚠️ `checks` 는 파일을 고쳤다 git 으로 되돌리므로 **만질 파일이 깨끗할 때만** 돈다.
⚠️ `links` 는 코드블록과 인라인 코드 안을 건너뛴다 — **오탐을 내는 도구는 사람이 꺼 버린다.**

### `mutate` — 손으로 거는 변이의 틀

```bash
universe mutate --file <경로> --from <문자열> --to <문자열> --expect <거부 사유> -- <명령>
universe mutate --self-test
```

검사를 새로 넣고 「정말 무나」 손으로 확인할 때 쓴다.
⛔ **종료코드로는 「물었다」와 「사고로 죽었다」가 구별되지 않는다.** 아래 갈래로 가른다
(⛔ **여기에 개수를 적지 마라** — 한 번 어긋났다. 표가 정본이다):

| 갈래 | 뜻 |
|------|----|
| ✅ 물었다 | 검증이 실패했고 **그 이유가 기대와 맞다** |
| ⚠️ 사유불일치 | 죽긴 했는데 **다른 이유로** 죽었다 (남이 대신 죽은 자리) |
| ⚠️ 겨냥실패 | 앵커가 **0곳 또는 여럿** — 어디를 바꿀지 모른다 |
| ⚠️ 변이미적용 | 치환했는데 **원본과 같다** |
| ⚠️ 변이본깨짐 | 싼 문법 검사가 죽었다 — **변이가 아니라 사고**다 |
| ❌ 놓쳤다 | 검증이 **통과했다** — 그 검사는 장식이다 |
| ⚠️ 기준선빨강 | **변이 전부터 빨갛다** — 무슨 변이를 넣든 「물었다」로 보인다 |

⛔ **겨냥은 「가드를 지운다」가 아니라 「조건을 만든다」로 잡는다.** 가드를 지우면 기준선이
이미 빨간 상태라 이 틀이 ⚠️ **기준선빨강**으로 옳게 거부한다 — **가드가 막으려는 그 조건을 만들어라.**
⛔ **변이 전에 원본으로 한 번 돌린다.** 그리고 **어떤 경로로 끝나든 원본을 되돌린다** —
커밋 안 된 파일을 변이시키는 일이라 여기서 새면 끝이다.

# 6. 바퀴 — `round`

```bash
universe round suggest   # 지금 라운드를 열 때인가 — 평가 안 된 커밋이 몇 개인가
universe round new "무엇을 할 것인가"
universe round close     # 평가표 검증 + 최고 판정이 아닌 축을 성운으로 승격
universe round audit     # 로그(정본)와 성운(파생)이 어긋나지 않는가
universe round which     # 어느 라운드가 열려 있는가
universe round open      # 성운의 열린 줄을 오래된 순으로
```

**나온다** — `close` 는 평가표 검증 결과와 **자동으로 성운에 실린 축**, `audit` 은 로그와 성운의 어긋남.

⛔ **`--force` 로 넘어가면 로그에 `forced:` 로 남고, `--why "<왜 넘는가>"` 를 함께 줘야 한다**(R65·R66).
그전엔 흔적이 아무 데도 없어 라운드가 **초록불이었던 것처럼** 닫혔다.
**도피구를 쓴 것 자체는 죄가 아니다 — 세지 않는 것이 죄다.**
⛔ `close` 는 평가표에 **빈 판정 · 근거 없는 칸 · 여러 축을 뭉갠 합성 등급**이 있으면 거부한다.
⚠️ `suggest` 는 **판정이 아니라 눈에 띄게 하는 것**이다 — 언제 여는지는 사람이 정한다.

# 7. 커밋 시점 관문 — `hooks`

```bash
universe hooks             # 켜졌는지 본다 (0=켜짐 · 1=꺼짐)
universe hooks --install   # 켠다
```

**나온다** — `core.hooksPath` 가 `.githooks/` 를 가리키는지, 그리고 **훅이 실제로 무엇을 거는지**
(그 파일을 읽어서 말한다).

git 훅은 **클론해도 자동으로 안 켜진다**(`.git/hooks` 는 커밋되지 않는다). 그래서 훅을
`.githooks/` 에 두고 이 명령이 `core.hooksPath` 를 가리키게 한다.

⛔ **여기 걸리는 관문의 목록과 시간을 이 문서에 옮겨 적지 않는다.** 정본은 `.githooks/pre-commit`
한 자리이고, 표를 옮겨 적었더니 훅은 다섯을 걸고 문서는 넷을 적고 있었다.
⚠️ 여기 거는 것은 **빠른 것만**이다 — 느린 것을 걸면 사람이 `--no-verify` 를 습관으로 만든다.
⚠️ 훅의 법칙 관측은 **우주 CLI 를 찾아야** 돈다. 못 찾으면 `⏭` 로 넘어가지 않고 **커밋을 막는다** —
여기서 ⏭ 는 「부품이 없다」가 아니라 **「당신 코드를 아무도 안 봤다」**라서 거짓 초록이 된다.
yarn berry 를 PnP 로 쓰면 실제로 이 자리에 걸린다(푸는 법은 [퀵스타트 1-3](01-quick-start.md)).

# 8. 전파 — `render` · `publish` · `beacon` · `wiki`

```bash
universe render      # 우주 상태 → 발행본
universe publish     # 위키로 (update — create 안 한다)
universe beacon            # 렌더가 바뀌었는데 발행 안 한 페이지를 찾는다
universe beacon --record   # 방금 발행했다고 기록한다
universe wiki        # 발행본과 저장소가 어긋났는가
```

**방향은 한쪽뿐이다.** 저장소가 정본, 위키는 뷰 — **위키에서 읽어 오지 않는다.**

⛔ **update 만 한다. create 는 안 한다.** 섞으면 발행할 때마다 중복 페이지가 쌓이고
**그 순간 정본이 둘**이 된다.
⛔ **좌표(사이트·스페이스·페이지 id)는 `.secret/` 에만 산다** — 커밋되는 `beacon/pages.json` 에
적지 마라. 좌표가 공개 저장소에 남은 사고가 이미 있었다(R151).
⚠️ 발행 전에 `observe` 가 초록불이어야 한다. **낡은 수치를 발행하는 것은 안 하느니만 못하다.**
⚠️ `beacon` 은 **위키 쪽에서 사람이 고친 것은 못 잡는다** — 「내가 마지막에 보낸 것」과
「지금 렌더 결과」만 본다. 그쪽은 `universe wiki` 가 바이트로 대조한다.

## Confluence 로 보낼 때 — 순서가 정해져 있다

```bash
node beacon/render.mjs              # ① 먼저 렌더한다 — publish 는 렌더를 안 한다
node beacon/publish.mjs --dry-run   # ② 무엇이 올라가는지 본다 (네트워크·자격증명 없이 돈다)
node beacon/publish.mjs             # ③ 실제 발행 — 자격증명이 있어야 한다
```

⛔ **①을 건너뛰면 낡은 산출을 민다.** 그건 안 미느니만 못하다 — 위키가 조용히 거짓이 된다.
⚠️ **좌표가 없는 장은 안 올라간다 — 그리고 이제 그렇게 말한다.** 예전엔 이름표보다 좌표가
적어서 몇 장이 **아무 말 없이** 빠지고 있었다. 올리려면 사람이 위키에 한 번 만들고
그 id 를 좌표 파일에 적어야 한다.

# 9. 플래그 표

⚠️ 이 표는 손으로 관리하지 않는다 — `universe args` 가 **받는 것 · 도구가 광고하는 것 · 이 문서**를
셋 다 대조한다. `universe round close --dry-run` 이 **구현돼 있는데 §7 집행자 목록에서 빠져
거부된** 적이 있다(R87). 시키는 대로 쳤을 때 죽는 자리다.

| 명령 | 플래그 | 무엇을 하는가 |
|------|--------|---------------|
| `universe init` | `--update` | **판올림 경로.** 기계(배달되는 폴더)만 다시 깐다 — 은하·성운·로그는 손대지 않는다. `--force` 는 그것들을 지운다(R91). ⚠️ **새 법칙·힘·궤도가 생겼으면 목록에 이어 주고 무엇을 이었는지 말한다** — 목록에 있다는 것이지 켰다는 것이 아니다(R119·R120) |
| `universe hooks` | `--uninstall` | 켠 커밋 관문을 끈다 |
| `universe round` | `--force` | 빨간 관문을 넘어 닫는다. **막지 않고 세어 기록한다**(R65) |
| `universe round` | `--dry-run` | 성운을 고치지 않고 판정만 본다 |
| `universe round which` | — | **어느 라운드가 열려 있는가.** mtime 으로 찾지 마라 — 복원이 그 값을 바꾼다(R88) |
| `universe round open` | — | **성운의 열린 줄을 오래된 순으로 내놓는다.** 손으로 grep 하지 마라 — 13줄로 세었는데 18줄이었다(R98) |
| `universe round close` | (frontmatter `closes:`) | 로그에 `closes: R89 변경 정직성 -> R95` 를 적으면 **성운 줄에 줄을 긋는다.** 못 찾으면 거부한다(R96) |
| `universe round` `universe lint` `universe observe` | `--why "<왜>"` | **기준선을 올릴 때** 사유. 없으면 안 올라간다 — 톱니는 내려가기만 쉽다 |
| `universe learn` | `--promote` | 궤적이 낸 후보를 성운에 붙인다 |
| `universe extract` | `--write` | **진짜로 뽑는다 — 모델을 궤적 한 건에 한 번 부른다.** 안 주면 무엇이 될지만 본다 |
| `universe extract` | `--galaxy <이름>` | 어느 은하의 궤적을 볼 것인가 |
| `universe orphans` | `--galaxy <이름>` | 한 은하만 본다 (안 주면 등록된 은하 전부) |
| `universe extract` | `--model <별칭>` | 카드를 뽑는 모델 (안 주면 엔진 기본) |
| `universe extract` | `--include-script` | **대본으로 돈 주행까지 뽑는다.** ⛔ 기본은 **뺀다** — 대본은 결정론이라 몇 번을 돌려도 하는 말이 같다(R159·R160) |
| `universe learn` | `--since <날짜>` | 볼 궤적의 범위를 자른다 (기본은 전부, 범위를 항상 찍는다) |
| `universe learn` `universe fix` `universe names` `universe enumeration` | `--update` | 지금 실측을 기준선으로 적는다 |
| `universe new` | `--base <커밋>` | 무엇이 새로 생겼는지 견줄 기준 커밋 |
| `universe new` | `--max-turns <수>` | (3차) 턴 예산. 기본 10 · 1~40. ⚠️ 진짜 은하는 조사에 턴이 많이 든다(실측: 10턴 중 7턴) |
| `universe new` | `--skills` | (3차) 지난 주행에서 뽑은 지식 카드를 브리핑에 넣는다. ⛔ **기본 꺼짐** — 결과를 낫게 하는지 아직 안 쟀다 |
| `universe new` | `--contract-first` | (3차) 요구사항을 **테스트로 먼저** 번역하고 **지금 빨간불인지** 확인한다. ⛔ **기본 꺼짐** |
| 전부 | `--universe <경로>` | 우주의 집을 직접 지정한다 (기본은 cwd 에서 탐색) |

내부 손잡이(`--model`·`--judge`·`--keep` 등)는 **문서에 안 적는 대신 사유를 적는다** —
`observatory/args-internal.json`. 사유 없이는 관문이 통과시키지 않는다.
