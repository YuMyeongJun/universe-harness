# 화면이 정본이다

> **사용자는 터미널에 절대 접근하지 않는다.** 프론트 화면에서 전부 한다.

⛔ 이건 취향이 아니라 **제품의 전제**다. CLI 는 **도구가 사는 곳**이고, 사람이 밟는 길은
**콘솔 화면**이다. 어떤 칸이 화면에 없으면 그 칸은 **그 사람에게 존재하지 않는다.**

## ⛔ 그래서 이 문서가 하는 일

「화면에서 되는가」를 **수로** 말한다. ⚠️ 「대충 다 되는 것 같다」로 닫지 않는다 —
이 저장소가 계속 겪은 그 사고다(「있는 줄 알았는데 아무도 안 부르고 있었다」).

## 지금 화면에서 되는 것 · 안 되는 것

| 칸 | 화면 | 터미널만 |
|---|---|---|
| 저장소 주소로 받아 오기 | ✅ `/intake` | |
| 채운 초안을 은하로 들이기 | ✅ `/intake` | |
| 위반 목록과 처방 보기 | ✅ `/violations` | |
| 주행 결과·판정 붙이기 | ✅ `/runs` | |
| **깃 로그인으로 레포 고르기** | ⛔ 서버만 있다 | `universe repos` |
| **구조 설명(아키텍처·메뉴) 셋팅** | ⛔ | `universe blueprint` |
| **TC 양식 내려받기·올려서 실행** | ⛔ | `qa/dist/tc/cli.js` |
| **fail 0 까지 반복** | ⛔ | `universe repeat` |

⚠️ 이 표는 **손으로 적은 것**이라 낡는다. 낡았는지는 관문이 잰다 —
`observatory/probe-console.mjs` 가 **화면이 부르는 API 와 서버가 내는 API 를 맞대어** 본다.

## ⛔ 화면이 지켜야 하는 것 (터미널이 없기 때문에 더 중요하다)

1. **못 쟀으면 ⚪ 로 말한다.** 터미널이 있으면 사람이 직접 쳐서 확인하지만, 없으면
   **화면이 유일한 창**이다. 빈 목록은 「없다」로 읽힌다 — 그게 이 제품에서 가장 비싼 거짓말이다.
2. **도구가 한 말을 요약하지 않는다.** 사람이 터미널에서 다시 볼 수 없다.
   ⇒ 실패 사유는 **그대로** 화면에 나와야 한다.
3. **「무시하고 계속」 갈래를 만들지 않는다.** 넘길 수 있는 관문은 넘겨진다.
4. **돈이 드는 것은 누르기 전에 말한다.** 모델을 부르는 칸(`blueprint --write` ·
   TC 초안)은 **몇 번 부를지**와 「⚠️ 토큰 사용량이 큽니다」를 **버튼 옆에** 적는다.
5. **토큰을 입력받지 않는다.** 인증은 그 기계의 `git`·`gh` 가 한다.
   ⛔ 화면에 토큰 칸을 만들면 그 값이 서버 로그·프로세스 목록에 남는다.
