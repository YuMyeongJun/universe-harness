# v0.2.0 — 관측소 연결

## 왜

v0.1.0 의 검사는 **형식**만 봤다 — 앞선 정원들과 같은 수준이었다.
법칙에 「재는 법」을 적어 놓고 재지 않으면 그것은 장식이다.

## 바뀐 것

- `laws/*.md` frontmatter `rules:` — 법칙 ↔ 규칙 id 매핑
- `laws/form.md` 신설 — 사내 컨벤션 6규칙의 주인. **opt-in**(합의 없는 은하에 걸지 않는다)
- `observatory/observe.mjs` — 커버리지 검사 + 은하 실측 + 드리프트 탐지 + `--update`
- `observatory/verify.mjs` — 게이트 + 관문(Contract)

## 검증 (실측)

첫 실행에서 **주인 없는 규칙 2건**(`quality/copy-state`·`quality/cohesion`)과
**문서 드리프트 2건**을 잡았다. `--update` 후 재실행 초록불.
