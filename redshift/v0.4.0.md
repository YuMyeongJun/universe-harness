# v0.4.0 — 힘과 궤도, 그리고 자기 개선 루프

## 왜

우주는 카카시 하네스의 3층 중 **지식층(법칙)만** 갖고 있었다.
에이전트층과 워크플로우층이 통째로 비어 있었고, 사용자가 두 번 지적했다.

더 중요한 것은 그 공백의 결과였다 — **낮은 평가가 갈 곳이 없었다.**
R01(은유 확인 B) · R02(원인 미규명) · R03(자동화 C) 이 전부 로그에만 남았고,
성숙도가 L4 에서 멈춰 있었다. L5 의 조건은 「낮은 평가가 다음 라운드의 작업이 된다」다.

## 바뀐 것

- **`forces/`** — 힘. 관측자(fundamental) + 발견 카탈로그 5(전부 실측에서 나온 후보)
  - 카카시 규칙 계승: **힘은 배달되지 않는다.** 명부만 배달하고 실물은 은하마다 새로 쓴다
  - 우주의 분기: **법칙은 배달된다** — 도메인에 매이지 않으므로
- **`orbits/`** — 궤도 3개: `round` · `observe-and-broadcast` · `nebula-to-star`
  - 「한 바퀴의 끝」을 못 적으면 궤도가 아니라 절차다
- **`redshift/`** — 버전 이력(이 문서 포함 5파일)
- **드리프트 기준선을 법칙 → 은하로 이관** — 법칙 하나가 은하 N개에 걸리므로 값 하나로는 담을 수 없다.
  `verify-laws.sh` 는 이제 법칙에 `measured:` 가 **있으면 오류**로 잡는다
- **성운 승격 5건** — 라운드 궤도 ⑤단계를 실제로 적용해 R01~R04 의 낮은 축을 올렸다
- `universe.config.json` — `forces`·`orbits` 등재 + 검사에 정합 추가

| 드리프트 새 경로 (기준선 없음 → `--update` → 재실행) | ⚠️5 → 갱신 → **✅5 "기준선과 같다"** |
