# 적색편이 (Redshift)

> 멀어진 만큼 빛이 붉어진다. **얼마나 왔는지는 스펙트럼이 말한다.**

우주의 구조가 바뀌면 버전을 올리고 `redshift/vX.Y.Z.md` 를 남긴다.
라운드 로그(`log/`)가 **무엇을 했나**라면, 여기는 **우주가 어떻게 달라졌나**다.

## 버전 규칙

| 자리 | 언제 |
|------|------|
| **Patch** | 문서 보강 · 오탈자 · 검사 메시지 |
| **Minor** | 새 법칙 · 새 힘 · 새 궤도 · 새 기관 |
| **Major** | 기관 구조 변경 · 법칙의 의미가 바뀜 · 은하 설정 스키마 파괴 |

⚠️ **법칙이 더 많이 잡게 바뀌면 Minor 이상이다.** 소비 은하의 게이트가 갑자기 빨개진다 —
얼마나 늘었는지 수치와 함께 적어라.

## 필수 절

```markdown
# vX.Y.Z — {한 줄}
## 왜        ← 무엇이 부족해서 바꿨나. 이전 버전의 어느 평가에서 나왔나
## 바뀐 것    ← 파일 단위
## 검증 (실측) ← 명령과 실제 출력. 추정 금지
```

## 이력

| 버전 | 무엇 |
|------|------|
| [v0.1.0](v0.1.0.md) | 우주 뼈대와 법칙 초판 |
| [v0.2.0](v0.2.0.md) | 관측소 연결 — 형식에서 동작으로 |
| [v0.3.0](v0.3.0.md) | 전파 · 공통 패키지화 · 엔진 벤더링 |
| [v0.4.0](v0.4.0.md) | 힘과 궤도 — 자기 개선 루프를 닫는다 |

⚠️ **v0.6.0 ~ v0.8.0 은 기록이 없다.** 그 판올림들이 기록 없이 지나갔고,
무엇이 바뀌었는지 지금은 알 수 없어 **지어내지 않는다.**
그 빈자리가 v0.9.0 이 관문을 세운 근거다 — `universe parts` 가 이제
**판에 대응하는 기록이 없으면 막는다.**
