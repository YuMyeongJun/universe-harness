# v0.5.0 — 빅뱅 1차 팽창

## 왜

우주의 이름이 「빅뱅」인데 **빅뱅이 비어 있었다.** 성운에 올라가 있던 항목이다.
법칙과 관측소는 있는데 **별을 만드는 것이 없으면** 우주는 검사기일 뿐이다.

## 바뀐 것

- `bigbang/bigbang.mjs` — `new <은하> <태양계> <별>` · `--dry-run` · `--out`
- `bigbang/templates/star/` — 별 템플릿 4파일(컴포넌트·훅·index·행동 계약 테스트)
- `bigbang/README.md` — 3단계 팽창 · 관문이 생성의 일부인 이유

**설계 결정: 관문을 생성 파이프라인 안에 넣었다.**
태어난 별은 쓰이기 전에 은하가 켠 법칙으로 검사되고, 위반이면 파일을 쓰지 않는다.
템플릿이 어긋나면 태어나는 별마다 같은 위반을 찍어내기 때문이다.

## 검증 (실측)

| 시험 | 결과 |
|------|------|
| 정상 템플릿 · dry-run | `✅ 태어난 별이 법칙을 지킨다` · **exit 0** |
| **일부러 어긴 템플릿**(`<div onClick>`·`gap-[16px]`·`bg-[#FFFFFF]`·`function`) | **5건 검출 · exit 1 · 파일 안 씀** |
| 실제 쓰기(`--out`) | 파일 4개 생성 확인 |
| 덮어쓰기 시도 | **exit 1** (덮어쓰지 않는다) |

⚠️ 첫 음성 시험에서 `... | sed` 뒤의 `$?` 를 읽어 **종료코드를 잘못 봤다**(0으로 보였다).
관측 법칙 §3 그대로다. 파이프 없이 다시 재서 1을 확인했다.
