# v0.1.0 — 우주 뼈대와 법칙 초판

## 왜

앞선 두 정원(카카시 하네스 · Blumn Enterprise Harness)을 분석한 결과, 둘 다 **형식만 검사**하고
동작은 사람이 봤다. 그 틈을 채우려면 먼저 **무엇이 옳은지**가 파일로 있어야 했다.

## 바뀐 것

- `README.md` · `universe.config.json` — 다섯 층(우주/빅뱅/은하/태양계/별) · 별의 주소
- `laws/` 9파일 — 메타 4(보존·중력·관측·광속) + 물질 4(토큰·시맨틱·네이밍·평탄성) + 색인
- `observatory/verify-laws.sh` — 법칙 집행 검사 6개
- `nebula/` · `log/` · `bigbang/` · `galaxies/`

## 검증 (실측)

첫 실행에서 **우주 자신의 중력 법칙 위반 2건**을 잡았다. 그리고 모델링 오류 1건이 드러났다 —
기관의 `parent` 를 `laws` 로 뒀는데 기관의 부모는 우주다. 고친 뒤 6개 검사 전부 통과.
