# v0.3.0 — 전파 · 공통 패키지화 · 엔진 벤더링

## 왜

세 가지가 동시에 걸렸다.
① 우주 상태를 사람이 읽을 곳이 없었다.
② 법칙 문서에 특정 은하의 수치가 박혀 있어 **공통 패키지가 아니었다.**
③ `observatory.path` 가 다른 저장소를 가리키는 **절대경로**라 배포가 불가능했다.

## 바뀐 것

- `beacon/` 신설 — 렌더(기관별 7페이지) + 페이지 좌표. **저장소가 정본, 위키는 뷰**
- 법칙에서 `measured:` 제거 → `examples/` 로 이관. **법칙은 은하를 모른다**
- `galaxies/` 비움 — 은하는 배달되지 않는다
- `observatory/engine/` — 엔진 3패키지 59파일 벤더링 + npm workspaces
- `verify-laws.sh` — 벤더링한 엔진과 렌더 산출물을 **자산이 아님**으로 제외(보존 법칙)

## 검증 (실측)

`engine selftest 14건` · `verify-laws exit 0` · `observe exit 0` · **절대경로 0건**.
원본 저장소는 무손상(그쪽 selftest 도 여전히 통과).

## 이 버전이 만든 결함

법칙에서 `measured:` 를 걷어내자 **드리프트 탐지가 조용히 죽었다** —
`--update` 가 `replace(/^measured:.*$/m)` 라 줄이 없으면 아무것도 안 한다.
v0.4.0 에서 기준선을 은하로 옮겨 고쳤다.
