# 우주의 법칙

> 법칙은 **읽으라고 있는 것이 아니라 막으라고** 있다.

별이 태어날 때 관측소가 이 법칙들로 검사하고, **하나라도 위반이면 별은 태어나지 않는다.**
이 폴더는 그 색인이다 — 법칙 하나가 파일 하나이고, 집행자는 관측소다.

## 무엇이 여기 사는가

**메타 법칙 — 우주의 물리.** 우주 자체가 지키는 법칙이다. 이 저장소의 모든 문서에 적용된다.

| 법칙 | 한 줄 |
|------|-------|
| [보존 법칙](conservation.md) | 지식은 우주 안, 별은 우주 밖 |
| [중력 법칙](gravity.md) | 중력에 묶이지 않은 것은 없다 — 고아 노트 금지 |
| [관측 법칙](observation.md) | 잰 것만 사실이다 |
| [광속 한계](light-speed.md) | 임계값은 깨끗한 상태의 실측값 이상이어야 한다 |

**여기에 「지금」이라고 적지 마라.** 재는 명령은 각 법칙 문서의 「재는 법」 절에 있다.

## 새 법칙을 추가할 때

1. `laws/{name}.md` 를 만든다. frontmatter 필수 — 특히 `applies_to` **(적용 범위)** 와
   `parent`/`related` **(중력 법칙 — 최소 1개 엣지)**.
2. **실제 은하에 걸어 보고 표본을 눈으로 세라.** 관측 법칙이다.
   작은 표본에서 오탐 0 은 아무것도 보장하지 않는다 — 이 우주의 재료가 된 규칙들도
   1,227개 파일에 걸고 나서야 **오탐 4종·153건**이 드러났다.
3. **양방향으로 증명하라** — 어기는 코드에서 잡히고, **옳은 코드에서는 안 잡힌다.**
   한쪽만 보면 「항상 통과」와 「항상 실패」를 못 가른다. 실제로 `bg-[var(--token)]` 처럼
   **옳은 코드를 벌하던** 규칙이 있었고, 대규모(1,227 파일)에서야 드러났다.
4. `universe.config.json` 의 `laws` 배열에 등재하고, 위 표에도 올린다 —
   목차에 없는 법칙은 관측소가 「있는데 아무도 모른다」로 막는다.
5. 관측소에 검사를 붙인다. **검사가 없는 법칙은 장식이다.**

## 함정 — 헛도는 법칙 하나가 관문 전체를 잃게 한다

오탐이 보이는데 고치기 어려우면 **법칙을 뺀다.**
헛도는 관문은 별이 무시하는 법부터 배우게 한다. 법칙 하나를 살리려고 관문 전체를 잃지 않는다.
