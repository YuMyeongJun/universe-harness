# R161 — 외우지 않고 쓰게 한다 — 대화형 입구를 열되 관문에는 손이 안 닿게

## 실행 요약

사용자의 말: **「명령어로 하려고 하면 외워야 하고 어렵다.」**

먼저 **재고 시작했다.** 아픔의 원인이 짐작과 달랐다:

| 잰 것 | 수 |
|---|---:|
| `universe` 가 받는 명령 | **32개** |
| 그중 **관문(`universe check`)이 알아서 부르는 것** | **22개** |
| 사람이 실제로 치는 것 | **10개** |

⇒ **외울 게 32개라서 어려운 게 아니라, 10개짜리 일을 32개로 보여 줘서** 어려웠다.
그래서 이 판의 절반은 「화면을 만든다」가 아니라 **「보여 주는 것을 가른다」**였다.

### 한 것

1. **`lib/commands.mjs`** — 명령 명부 한 자리(`daily` 10 / `gate` 22 · 한 줄 설명).
   예전엔 도움말 문자열이 `bin/universe.mjs` 안에 **따로** 있어서 배분표와 **두 개의 손 목록**이었다
   (R47 이 관문 목록에서 겪은 그것 — 실제로 `orphans`·`extract` 를 더할 때 두 곳을 고쳤다).
   이제 도움말은 명부에서 **만들어진다.**
2. **`bin/menu.mjs`** — 대화형 입구. `node:readline/promises` 만 쓴다(**의존성 여전히 0**).
   고른 것에 **필요한 것만** 묻고, 은하·태양계 이름은 좌표에서 **읽어서** 보여 준다.
3. **`bin/universe.mjs`** — 인자 없음 + **TTY 일 때만** 메뉴. `--help` 는 10개, `--help --all` 은 32개.
4. `docs/02-usage.md` 에 셋 다 적었다.

### ⛔ 이 판의 제약 — 화면이 관문을 약하게 만들면 안 된다

「느려진 관문은 아무도 안 본다」의 사촌이 **「넘길 수 있는 관문」**이다. 메뉴는 고르기 쉬운
만큼 **넘기기도 쉬워진다.** 그래서 「무시하고 계속」·「이번만 건너뛰기」 갈래를 **아예 안 만들었고**,
그것이 생기는지를 **변이로 못 박았다**(아래).

## 결과

| 넣은 검사 | 무는가 (일부러 깨서 잼) |
|---|---|
| 명부↔배분표 양방향 | ✅ 명부에서 빼면 문다 / ✅ 배분표에 없는 것을 명부가 광고하면 문다 |
| 화면이 관문을 넘기는 갈래 | ✅ 코드 줄로 넣으면 문다 (**관문에 상설 변이로 박음**) |
| 비-TTY 에서 대화형으로 새는 것 | ✅ 가드를 떼면 문다 (**관문에 상설 변이로 박음**) |
| stdin 끝(Ctrl-D)을 곱게 처리 | ✅ 되돌리면 문다 |
| 3차의 비용 확인 | ✅ 빼면 문다 |
| 메뉴가 만드는 명령줄 | ✅ `--expand` 를 안 붙이게 하면 문다 |
| 기본 도움말이 관문 명령을 숨기는가 | ✅ 전부 보이게 하면 문다 |
| 한글 두 칸 정렬 | ✅ 글자 수로 되돌리면 문다 |

`node bin/check.mjs` — **26개 · 빨간불 0** · 변이 시험 **45/45 전부 물었다** · 의존성 **0**.

### 이 판에서 검사가 나를 네 번 물었다

1. **주석을 재고 있었다.** 「이런 갈래를 만들지 않는다」고 적어 둔 **문서 문구**에 검사가
   스스로 걸렸다 — 즉 **문구가 있으면 진짜 갈래를 못 알아본다.** 이 세션에서 같은 종류로
   검사가 죽어 있던 적이 있다(정규식이 브리핑 문구에 걸려 거절을 꺼도 통과했다).
   ⇒ 주석을 걷어내고 **코드만** 재게 고쳤고, **분모 가드**를 붙였다.
2. **시험이 환경을 재고 있었다.** 메뉴 주행을 저장소의 `galaxies/` 로 몰았더니 **배달본에서
   빨간불**이 났다 — 배달본엔 등록부가 없어 메뉴가 「직접 입력」으로 갈렸고 대본 답이 밀렸다.
   「원본이 도는 것과 배달본이 도는 것은 다르다」를 시험이 직접 맞았다. ⇒ 자기 픽스처를 쓰게 고쳤다.
3. **`bin/` 은 배달되지 않는다**(CLI 는 패키지에서 돈다). 모르고 읽다가 배달본이 죽었다.
   ⇒ 기존 `cliSource` 검사와 같은 방식으로 **「못 쟀다」고 말하고** 넘긴다(§8 · 조용히 넘기지 않는다).
4. **내 변이가 헛것이었다.** 「한글 두 칸」 변이가 정규식이 안 맞아 **안 들어갔는데**, 나는
   그걸 「검사가 약하다」로 읽을 뻔했다. 변이가 진짜 들어갔는지 먼저 확인하고 다시 겨눴다.

### ⛔ 그리고 내가 저장소를 더럽혔다

배달본 실패를 재현하려다 **`bin/init.mjs` 를 저장소 루트에서 돌려** 우주를 저장소 안에
깔아 버렸다(`universe/`). 그 부작용으로 `.gitignore` 가 바뀌고, 구조 그림이 그 폴더를
그렸고, **`orbits/round.md` 의 그림 참조가 하나 늘어 변이 하나가 안 물게** 됐다.
치우고 `.gitignore` 를 되돌린 뒤 다시 그렸다. ⚠️ **재현을 임시 폴더 밖에서 하면 안 된다.**

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | A+ | 넣은 검사 8종을 **전부 일부러 깨서** 무는 것을 봤고, 그중 둘(관문 넘기기·비-TTY 누수)은 `verify-checks` 에 **상설 변이로 박았다** — 일회성 확인은 다음 사람에게 안 남는다. 조준이 틀린 변이 하나는 다시 겨눴다 |
| 실측 기반성 | A+ | 「32개 중 사람이 치는 것 10개」는 배분표를 **읽어서** 센 것이고 문서 수치도 거기서 나온다. 비-TTY 검사는 소스에 `isTTY` 가 있는지 보지 않고 **진짜로 자식을 띄워 매달리는지** 잰다 |
| 변경 정직성 | A | 검사가 나를 네 번 물었고 네 번 다 적었다. 저장소를 더럽힌 것도 적었다. ⚠️ 다만 **실제 터미널에서 사람이 끝까지 써 본 적은 없다** — 대본으로만 몰았다(§8) |

## 다음 단계

- ⚪ **실제 TTY 에서 사람이 한 번 써 봐야 한다.** 대본 주행은 배선을 재지 화면을 안 잰다 — 지금 「쓸 만한가」는 **못 쟀다**.
- ⚪ `verify-coordinates`·`beacon/wiki.mjs` 는 관문 목록엔 있는데 **`universe <이름>` 으로는 못 부른다.** 명부를 쓰다 양방향 검사에 걸려서 알았다 — 배분표에 더할지 판단이 남았다.
