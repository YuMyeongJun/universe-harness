# R52 — 문서가 시키는 대로 하면 되는가 — 빠른 시작을 그대로 따라 한다

## 실행 요약

R43~R51 에서 도입 경로가 크게 바뀌었다(`init` 이 gitignore 를 쓰고, `galaxy` 명령이 생기고,
`observe` 는 `--universe` 가 필요하고, 컴파일 관문이 붙었다).
**문서가 아직 그 말을 하는지는 안 쟀다.** 거짓말하는 문서는 없는 문서보다 나쁘다.

빈 저장소를 만들어 **퀵스타트를 한 줄씩 그대로 쳤다.**

## 결과

### ⛔ 문서가 남의 패키지를 받게 시키고 있었다

퀵스타트가 `npx universe init` 을 **네 번** 시킨다. 그런데 npm 의 `universe` 는
**crossfilter/universe — 「The fastest way to query and explore multivariate datasets」**다.
이 우주와 아무 상관이 없고, 이 우주는 `private: true` 라 **배포된 적이 없다.**

그대로 따라 하면 **엉뚱한 패키지를 내려받는다.**

⚠️ 그리고 **도구 자신의 오류 메시지**도 같은 것을 시키고 있었다 —
`lib/home.mjs` 의 「소비 저장소라면 먼저 깔아라: `npx universe init`」.
사람이 그 말을 가장 믿는 순간은 **막혔을 때**다. 처음엔 `docs/` 만 훑다가 놓쳤고, 코드까지 넓혔다.

### ⛔ 버전이 두 자리에서 세 판 갈려 있었다

`package.json` **0.5.0** · `universe.config.json` **0.8.0**.
위키의 「v0.8.0」은 config 를 읽고 npm 은 package.json 을 읽는다 — 어느 쪽이 진실인지 모른다.
R47 과 같은 종류(같은 지식이 두 자리)라 **관문으로 걸었다.**

### 문서를 실제와 맞췄다

| 무엇 | 전 | 후 |
|------|----|----|
| 설치 | `npx universe init` | `node <우주>/bin/init.mjs` + **왜 npx 가 아닌지** |
| 은하 등록 | 40줄 JSON 을 손으로 | `bin/galaxy.mjs` 로 초안 → TODO 채우기 |
| 관측 | `npx universe observe` | `bin/universe.mjs observe --universe ./universe` |
| 별 | 「관문 통과 못 하면 파일을 안 쓴다」 | **법칙 관문은 그렇고, 컴파일 관문은 쓴 뒤에 잰다**(실패해도 남겨 둔다) |
| — | (없음) | 테스트 없는 은하엔 행동 계약을 안 만든다는 것 |

### 따라 하다 두 개 더 잡았다

1. `npm init -y` 가 심는 **가짜 `test` 스크립트**(`echo "Error: no test specified"`)를
   진짜 명령으로 읽었다. 그대로 두면 빅뱅이 행동 계약 파일을 만들고 **R44 가 그대로 재현된다.**
2. `--out` 을 줬는데도 **우주의 집을 찾다 죽었다.** 쓸 자리를 이미 정한 사람에게
   필요 없는 것을 요구하면, 도구는 안 쓰이는 법부터 가르친다.

고친 퀵스타트를 **다시 한 줄씩 쳐서** 1~3단계가 문서대로 도는 것을 확인했다
(초안 6곳 TODO → `observe` 가 exit 1 로 거부).

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | 통과 | 「버전이 한 값인가」와 「남의 패키지를 시키지 않는가」를 `universe parts` 에 걸었다(문서 9편 + 코드 24개). 양쪽 다 되돌려 exit 1 확인 |
| 실측 기반성 | 통과 | 문서를 **읽지 않고 실행했다.** `npm view universe` 로 그 패키지가 무엇인지 확인했고, 고친 뒤 다시 실행해 도는 것까지 봤다 |
| 변경 정직성 | 통과 | 「관문 통과 못 하면 파일을 안 쓴다」가 컴파일 관문에는 **더 이상 참이 아니라는 것**을 문서에 적었다. 좋게 들리는 옛 문장을 남겨 두지 않았다 |
