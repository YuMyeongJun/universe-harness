# R80 — 도구의 말이 맞는가를 재는 갈래

## 실행 요약

R79 가 **거부 시험**을 만들었다 — 「멈춰야 할 때 멈추는가」.
그런데 **멈추지 않는 것이 옳고 말만 달라져야 하는** 성질이 있다.

R73 의 `--promote` 가 그렇다: 이미 판단한 것은 **안 올리고** 「올릴 것이 없다」고 말해야 한다.
⛔ **종료코드는 양쪽 다 0** 이라 거부 시험으로는 못 잡는다.

R79 는 「아직 근거가 없다」고 미뤘는데, 그것을 요구하는 사례가 **둘** 모였다.

## 결과

**말 시험** 갈래를 만들었다 — 도구의 말도 산출물이다(R78 에서 그렇게 적었다).

```
── 도구가 맞는 말을 하는가

  ✅ learn --promote 가 이미 판단한 것을 다시 안 올린다
  ✅ observe 가 규칙의 주인을 빠짐없이 셌다고 말한다
```

필터를 빼고 시험하니 **말 시험만 잡았다** — 종료코드는 그대로 0 이었다.

### ⚠️ 시험이 실패할 때 저장소를 더럽혔다

필터가 깨진 상태에서 `--promote` 는 **성운에 줄을 덧붙인다.**
즉 **시험 자체가 오염원**이 된다(R62 의 잔해와 같은 종류).

⇒ 만진 파일을 **들어올 때의 내용으로 되돌린다.** 실패한 채로 돌려도 성운이 그대로인 것을 확인했다.

R73 의 「미흡」을 **일부** 갚았다 — `--install` 은 여전히 못 박는다(훅을 건드린다).

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | 통과 | 말 시험 둘을 넣고 필터를 빼서 무는 것을 확인했다. 실패해도 저장소가 안 더럽혀지는 것까지 확인했다 |
| 실측 기반성 | 통과 | 「종료코드는 양쪽 다 0」을 **실제로 재서** 확인했다 — 그래서 이 갈래가 필요하다는 근거가 생겼다 |
| 변경 정직성 | 통과 | R73 의 미흡을 **일부**만 갚았다고 적었다. 시험이 오염원이 되던 것도 먼저 적었다 |
