# R123 — 깔기도 전에 치면 뭐라고 하는가 — 새 사람이 실제로 막히는 자리

## 실행 요약

R122 가 **행복한 길**을 잠갔다. 새 사람이 실제로 막히는 곳은 **잘못 친 길**이라 그것을 밟았다.

## 결과

**안내는 훌륭하다.** 깔기 전에 아무 명령이나 치면:

```
우주를 찾지 못했다 — `universe.config.json` 이 있는 디렉터리가 없다.
  · 소비 저장소라면 먼저 깔아라:  node <우주-저장소>/bin/init.mjs
    (⛔ `npx universe` 가 아니다 — npm 의 그 이름은 남의 패키지다)
  · 다른 곳에 있다면:            --universe <경로>  또는  UNIVERSE_HOME=<경로>
  (찾기 시작한 자리: …)
```

문제·처방·대안·**찾은 자리**까지 말한다. 여섯 명령 전부 `exit=1` 이다.
⚠️ 처음엔 `exit=0` 으로 보였는데 **파이프 뒤의 `$?`** 였다(§3) — 파이프 없이 다시 쟀다.

**둘이 나왔다.**

| 무엇 | 왜 나쁜가 |
|------|-----------|
| git 저장소가 아닌 곳에 **조용히 깔린다** | `.githooks` 를 「커밋 관문」이라 소개하는데 **켤 수 없다.** 막지는 않되(일부러 그럴 수 있다) 조용히 지나가지 못하게 했다 |
| `.githooks` 소개에 **「약 1.5초」** | R118 이 훅을 자기 시간 찍게 고쳤는데 **이 줄은 놓쳤다.** 실측은 2.8초 — 수를 지웠다 |

⚠️ 그리고 그 검사를 **깔리는 자리**로 고쳤다 — 처음엔 `cwd` 를 봤는데, 훅은 `--dir` 로 지정한
**그 저장소**에 걸린다. 우주 안에서 남의 폴더에 깔면 cwd 만 보고 「git 이 있다」고 착각한다.

말 시험 7 → **8건**.

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | 통과 | git 없는 자리에 깔면 말한다 — 말 시험이 잰다 |
| 실측 기반성 | 통과 | 여섯 명령의 종료코드를 파이프 없이 쟀다. 낡은 수도 실측(2.8초)과 대조했다 |
| 변경 정직성 | 통과 | 내가 §3 을 잠깐 어긴 것과, 검사 대상을 cwd → 대상 폴더로 고친 것을 적었다 |
