# R153 — OpenRouter 레인 — 구독이 없어도 3차를 돈다. 다만 몰래 갈아타지 않는다

## 실행 요약

0.10 의 둘째 칸. 지금까지 3차 팽창은 **Claude Code 구독이 있어야만** 돌았다.

⚠️ **먼저 걷어낼 오해**: 「모델이 없으면 아무것도 못 한다」는 **틀렸다.**
1차(결정론 규칙)와 2차(`--static-only` 게이트)는 **원래 모델 없이 완전히 돈다.**
모델이 필요한 것은 **3차뿐**이고, 그래서 이 레인이 여는 것도 3차 하나다.

## 결과

### 이음매는 이미 있었다 — 엔진 코어를 안 건드렸다

`nebula.mjs` 의 `ask` 가 그 자리다. `createClaudeAsk`(구독)·`createScriptedAsk`(대본·0원)가
이미 같은 계약(`({input, sessionId}) => {text, sessionId, isError, costUsd, usage}`)을 쓴다.
⇒ 레인을 **하나 더 얹었을 뿐**이다.

| 레인 | 무엇으로 | 돈 |
|---|---|---|
| `subscription`(기본) | `claude` CLI · `ANTHROPIC_API_KEY` 를 자식에서 지운다 | 그 기계의 구독 |
| `openrouter` | HTTP · 모델 슬러그 | **과금된다** |
| `script` | JSONL 대본 | **0원** |

### CLI 와 결정적으로 다른 것 — **세션이 없다**

`claude -p` 는 `--resume` 으로 **서버가 대화를 들고 있다.** OpenRouter 는 무상태 HTTP 다.
⇒ 클로저 안에 `Map<sessionId, messages[]>` 를 두고 **우리가 이력을 나른다.**
안 나르면 에이전트가 매 턴 기억을 잃고 같은 patch 를 다시 낸다.
그렇게 해야 `ask` 계약이 그대로고 부르는 쪽은 레인을 몰라도 된다.

### ⛔ 자동 전환 금지 — 이 라운드의 핵심

R145 가 못 박은 것이 「모드가 바뀌는데 아무도 안 잰다」였다(키가 환경에 있으면 조용히
과금 경로로 넘어가던 자리). **같은 실수를 레인에서 반복하지 않는다.**

실측으로 확인했다 — `claude` 를 PATH 에서 뺀 채 3차를 돌렸다:

```
🛤  레인 — 구독 (claude CLI · ANTHROPIC_API_KEY 를 자식에서 지운다)
⛔ 에이전트 호출이 두 번 실패했다: `claude` 를 못 찾았다 …
```

⇒ **openrouter 로 안 넘어갔다.** 구독 레인에서 옳게 죽었다.

### 그런데 그 화면이 생 스택이었다 — 고쳤다

처음엔 `Error: spawn claude ENOENT` 였다. **구독이 없는 사람이 만나는 첫 화면**이 그것이다 —
무엇이 없는지도, 다른 길이 있는지도 안 말한다. 「도구가 없는 것」은 실패가 아니라 **다른 사건**이다
(R146 이 컴파일 관문에서 가른 그것). 신호로 바꾸고 **세 갈래를 다 말한다**:

```
`claude` 를 못 찾았다 — 이 레인은 Claude Code CLI(구독)로 돈다.
   · 구독이 있으면: CLI 를 깔고 로그인하라
   · 구독이 없으면: `--lane openrouter` 로 돌 수 있다 (**과금된다**)
   · 배선만 보려면: `--lane script --agent-script <대본>` (모델 호출 0회)
```

### 키가 없으면 **별을 쓰기도 전에** 멈춘다 — 한 번 밟고 고쳤다

처음엔 레인 검사를 3차 블록 안에 뒀는데 그 자리는 **별을 이미 쓴 뒤**였다.
키 없이 `--lane openrouter` 를 부르자 「멈춘다」고 말해 놓고 **은하에 별을 남겼다.**
「못 잴 곳에 별을 쓰지 않는다」가 이 검사의 이유인데 **그 이유를 스스로 어긴 것**이다.
⇒ 이름과 필수 환경변수 검증을 **별보다 앞으로** 올렸다. 부품 시험이 그 순서를 못 박는다.

### 타이머를 안 꺼서 프로세스가 안 죽었다

부품 시험이 **끝나고도 안 끝났다.** 답은 다 받았는데 600초짜리 abort 타이머가 살아 있어
이벤트 루프가 안 비었다. `finally` 로 끈다. ⚠️ `unref` 로도 되지만 그건 **끄는 것이 아니라
안 세는 것**이다 — 진짜로 끈다.

### 잰 법 — 진짜 호출 **0회**

가짜 `fetch` 로 계약만 쟀다:

| 잰 것 | 결과 |
|---|---|
| 이력을 나르는가 | ✅ 2턴째 `system·user·assistant·user` |
| 비용을 지어내는가 | ✅ 보고된 값만 나른다 · 없으면 `null` |
| `usage.include` 를 켜는가 | ✅ 안 켜면 비용이 안 와서 **추정하게 된다** |
| 도구를 넘기는가 | ✅ 안 넘긴다 — 훔쳐보는 갈래가 구조적으로 없다 |
| 빈 답을 통과로 세는가 | ✅ `isError` (claudeCli 가 빈 stdout 으로 당한 자리) |
| 401 을 던지는가 | ✅ 신호로 바꾼다 — 던지면 게이트가 통째로 날아간다 |

⚠️ **진짜 OpenRouter 호출은 한 번도 안 했다** — 키가 없다. 그러므로 「돈다」가 아니라
**「계약을 쟀다」**고만 적는다(§8). 키가 생기면 1회 주행으로 다시 재야 한다.
