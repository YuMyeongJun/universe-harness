# R06 — 라운드 궤도 자동화

## 실행 요약

`universe round new|close` 를 만들었다. 라운드 궤도 ⑤단계(낮은 축 → 성운 승격)는 그동안
**사람이 손으로** 했고, 그래서 R01~R03 의 낮은 축이 전부 로그에만 남았다.
이제 기계가 한다 — 평가를 대신 쓰지는 않고, **빠뜨리지 못하게** 한다.

그리고 드리프트 원인 규명을 자동화했다. 기준선 커밋과 HEAD 사이를 관측소가 스스로 훑는다.

## 결과

| 산출 | 내용 |
|------|------|
| `bin/round.mjs` | `new`(로그 뼈대) · `close`(검사 → 평가 확인 → 승격) |
| `observatory/observe.mjs` | 드리프트 시 **자동 원인 진단**(커밋 목록 · 변경 큰 파일 · 워킹트리 오염) |
| `bin/init.mjs` · `seed/nebula.md` | 씨앗 — 빈 저장소에 깔아 실동작 확인 |
| `.claude-plugin/` · `plugins/universe/` | 플러그인 껍데기 + `/universe` 스킬 |
| `docs/` 6편 · SVG 3장 | 퀵스타트~출처 |

`round close` 가 막는 것(전부 실측 확인): 검사 빨간불 · 평가 절 없음 · 판정 빈 축 ·
**근거 없는 등급** · 합성 등급.
승격 시험: 4축 중 `B` 하나만 정확히 골라 성운으로 올렸다.

드리프트 진단 시험: 커밋 하나로 임의값 2개를 늘리자 `기준선 이후 이 경로를 건드린 커밋 1개:
9ebbbdd` 와 가장 많이 바뀐 파일까지 자동으로 짚었다.
