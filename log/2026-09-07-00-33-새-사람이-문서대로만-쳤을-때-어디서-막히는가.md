# R121 — 새 사람이 문서대로만 쳤을 때 어디서 막히는가

## 실행 요약

사용자가 처음 말한 목표는 「**명령어 한 번으로 서비스가 나오는 마법**」이다.
새 사람이 **문서대로만** 쳤을 때 어디서 막히는지, 빈 저장소에서 그대로 쟀다.

## 결과

⛔ **세 번째 명령에서 막혔다 — 그것도 조용히.**

```
① node <우주>/bin/init.mjs              ✅
② universe galaxy my-app --dir .        ✅ 좌표 초안을 만든다
③ universe observe --universe ./universe  ✅ ← **초록불인데 아무것도 안 쟀다**
     ── 은하 없음 — 실측할 대상이 없다. 커버리지만 본다.
```

좌표 파일은 `universe/galaxies/my-app.json` 에 있는데 **`config.galaxies` 가 비어 있었다.**
`galaxy` 가 파일만 쓰고 **이름을 목록에 안 올린다.** 새 사람이 처음 걷는 길에서
**「못 쟀다」가 「통과」로 보인 것**이다(§8).

**두 자리를 고쳤다.**

| 어디 | 무엇 |
|------|------|
| `galaxy` | 이름을 `config.galaxies` 에 올리고 **왜 올리는지 말한다** — 「안 올리면 관측이 아무것도 안 재고 초록불을 낸다」. ⚠️ `--out` 으로 딴 데 쓸 때는 안 올린다 |
| `observe` | 좌표 파일이 있는데 목록이 비면 **초록불을 안 준다** — 「없는 것」이 아니라 「빠뜨린 것」이다 |

**고친 뒤 문서 경로가 끝까지 돈다** — 빈 저장소에서 다시 밟았다:

```
init → galaxy(목록에 올림) → observe(TODO 를 거부) → TODO 채움
     → observe --update(기준선 심음) → observe ✅ → new ⭐ 별이 태어났다
```

⚠️ 마지막에 「**이 별에는 지켜 줄 계약이 없다**」가 뜬다 — 은하가 `commands.test` 를 안 채웠기
때문이고, **그렇게 말하는 것이 옳다**(R44). 막지 않고 말한다.

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | 통과 | 목록을 비우면 관측이 초록불을 안 준다 — 말 시험에 박았다 |
| 실측 기반성 | 통과 | 빈 저장소에서 문서 순서를 그대로 밟았다. 고친 뒤 끝까지 도는 것도 밟아서 확인했다 |
| 변경 정직성 | 통과 | 마지막 경고(계약 없음)는 **고치지 않고 옳다고 적었다** |
