# 라운드 기록 (Log)

경로: `log/{yyyy-MM-dd-HH-mm}-{title}.md`

## 필수 절

```markdown
## 실행 요약
## 결과          ← 파일 경로 · 실측 수치 포함
## 평가          ← 생략 금지
## 다음 단계     ← 실행할 것은 성운으로 승격. 여기 쌓아 두지 않는다
```

## 평가 규칙

- **축 / 판정 / 근거** 표로 쓴다. 근거 없는 등급은 무효다.
- **합성 등급 금지** — 여러 축을 "종합 B+" 로 합치지 않는다.
- **정직성 축을 포함한다** — 이번 작업 이전부터 있던 결함을 구분해 적었는가,
  변경이 없는 것을 없다고 적었는가.

## 왜 정직성인가

원형이 된 정원의 로그에 이런 축이 실제로 있었다:

> **변경 정직성: High** — 0.10.1 파손이 이번 작업 이전부터 있던 것임을 구분해 적었고,
> v1.0.0 이 코드 변경 0 의 순수 정렬임을 숨기지 않았다.

우주도 같다. **잰 것만 사실이고, 안 한 것은 안 했다고 적는다.**
