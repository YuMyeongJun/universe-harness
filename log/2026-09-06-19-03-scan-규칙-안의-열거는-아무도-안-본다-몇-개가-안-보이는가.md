# R110 — scan 규칙 안의 열거는 아무도 안 본다 — 몇 개가 안 보이는가

## 실행 요약

R109 가 답 없이 남긴 자리 — 「`scan:` 안의 열거를 어떻게 볼 것인가」.

## 결과

**하나. 셋이 통째로 안 보였다.** 규칙 20개 중 `pattern:` 이 17, `scan:` 이 3인데
감사는 `pattern:` 만 봤다. 안 보이던 셋은 전부 이름을 쓴다:

| 규칙 | 쓰는 이름 | 무엇인가 |
|------|-----------|----------|
| `quality/copy-state` | `default*` 접두사 · `useState`·`useEffect` | 라이브러리 API 관례 |
| `quality/cohesion` | `Props`/`Prop` 접미사 · `interface`·`type`·`boolean` | TS 문법 + React 관례 |
| `quality/magic-number` | `const`·`enum`·`export`·`test`/`spec`·`Code` | TS 문법 + 테스트 파일 관례 |

패턴이 없으면 **그 규칙 안의 정규식 전부**를 본다. 넓게 잡고 **판단을 강제**한다 —
12 → **15개**가 보이고, 새로 드러난 둘에 사유를 적었다.

⚠️ `cohesion` 의 `Props` 접미사는 **관례라 어긋나는 팀이 있을 수 있다**(`IUserProperties`).
그때는 **놓치는 쪽으로 틀린다** — 옳은 코드를 벌하지 않는다. 그 판단도 기준선에 적었다.

**둘 — 재는 길에 더 큰 것이 나왔다. 열거를 넓혀도 다시 안 물었다.**

`default*` 를 `initial*`·`preset*` 까지 넓혀 봤더니 **초록불이었다.** 처방 감사는
「문구가 바뀌었는데 판단은 그대로」를 잡는데(R55) 열거 감사는 **판단한 이름을 기억하지 않았다.**

기준선을 처방 감사와 같은 모양(`{열거, 판단}`)으로 바꿨다. 이제 이렇게 문다:

```
⛔ 열거가 바뀌었는데 판단은 그대로인 규칙 1개: quality/copy-state
   기준선: Props default set useEffect useState
   지금  : Props default initial preset set useEffect useState
```

⚠️ 옛 모양(문자열)도 계속 읽는다 — 갈아타는 동안 깨지지 않게.

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | 통과 | 열거를 넓히면 문다(known-positive). 안 보이던 셋이 이제 판단을 요구한다 |
| 실측 기반성 | 통과 | 17/3 · 12→15 는 잰 수다. 셋이 쓰는 이름을 하나씩 뽑아 봤다 |
| 변경 정직성 | 통과 | `Props` 접미사가 관례라 놓칠 수 있다는 것을 판단에 적었다 |
