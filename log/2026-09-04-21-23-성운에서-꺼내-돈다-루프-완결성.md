# R07 — 성운에서 꺼내 돈다 — 루프 완결성

## 실행 요약

성운에 열려 있던 항목은 하나였다 — **「승격은 자동화됐지만 성운에서 꺼내 도는 바퀴는
아직 한 번도 안 돌았다」**(R04 루프 완결성 B). 이 라운드가 그 바퀴다.

돌리기 전에 **먼저 새는 곳을 막았다.** 승격 5건이 배포판화 작업에 덮여 성운에서
사라진 사건이 있었고, 손으로 되살리는 대신 `universe round audit` 을 만들었다 —
**로그를 정본, 성운을 파생**으로 보고 대조한다. 실행하자 4건을 정확히 찾아냈다.

## 결과

| 무엇 | 어떻게 확인했나 |
|---|---|
| `round audit` — 사라진 승격 4건 적발 · 복원 | `audit` exit 1 → `--restore` → 재감사 exit 0 |
| 감사의 **자기 오탐 2건** 수정 | ① 대조 열쇠를 근거 문구 → 라운드+축 ② 열린 라운드의 빈 평가표 제외. 둘 다 한 줄 지웠다 되돌리는 음성 시험으로 증명 |
| **네 스테이지 전부 재현** | 결함 `FAILED`(s01 0.78 · s03 0.751) → 오라클 `SOLVED`(둘 다 0.96). 양방향 |
| **이 프로젝트 최초의 SOLVED** | `s04` 에이전트 1회 `reward 0.81`, 궤적 원본 확인 |
| 엔진이 빨간 것을 초록불로 보고하던 결함 2건 | `reset()` boot build 무시 → LLM **14회 → 0회** · `submit()` 채점 예외 → 빨간 신호로 |
| **LLM 비용 기록** | 궤적에 `{kind:'cost'}` · 에피소드 끝에 표시. 한 호출이라도 보고가 없으면 합계를 `null` 로 |
| 모르는 플래그 거부 | `--oracle` → exit 1 · `list` → exit 0 |
| `universe links` | 깨진 링크 7건 → 0건 |
| 3차 팽창 · Next.js 플러그인 | 요구사항→화면 exit 0 · 우주가 Vite 밖으로 처음 나감 |
| `CONTRIBUTING.md` | 없는 것을 가리키던 링크가 실은 필요한 문서였다 |

**이 바퀴에서 가장 값진 것은 기능이 아니라 두 번의 자기 적발이다.**

첫째, 감사를 만들자마자 **감사가 자기 오탐을 냈다.** 두 번 다 「재는 도구가 틀렸다」였고,
두 번 다 음성 시험이 잡았다.

둘째, 비용을 기록하자마자 **`--oracle` 이라는 없는 플래그로 돈이 나가고 있었다**는 것이
드러났다. 파서가 모르는 플래그를 조용히 삼켜서, 나는 공짜 모드인 줄 알고 유료 주행을
돌리고 있었고 **갈래에게도 같은 지시를 내려 뒀다.** 화면에 뜬 것은 전부 정상이었다.
이것을 관측 법칙 **§7** 로 박았다 — 「도구가 모르는 입력을 조용히 삼키면, 안 켜진 모드가
켜진 것처럼 보인다」.

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | A | 이 라운드에서 늘린 검사가 전부 **실제로 물었다** — `audit` 이 4건 적발(exit 1), `links` 가 7건 적발, 플래그 거부가 `--oracle` 을 exit 1 로 막음. 넷 다 음성 시험(지웠다 되돌리기)으로 확인했다 |
| 실측 기반성 | A | 모든 수치를 파이프 없이 직접 재고 원본을 열었다 — SOLVED 는 궤적 JSONL 원본, 비용은 CLI 자기 보고, 스테이지 판정은 결함/고침 양쪽. 갈래가 준 수치는 그대로 인용하지 않고 재현했다 |
| 변경 정직성 | A | 못 한 것을 적었다 — 3차는 **요구사항 충족 여부를 못 재고 새 기능에 테스트가 안 생긴다**, Next 플러그인은 **진짜 Next 저장소로 미검증**, s02·s03·s01 은 **오라클로만 풀었다**(에이전트 미주행). 내가 틀렸던 것(`--oracle` 지시)도 적고 갈래에게 정정을 보냈다 |
| 루프 완결성 | B | **바퀴는 돌았다** — 성운에서 꺼내 열고, 도는 중에 새 항목 2건을 성운에 올리고, 감사로 새는 것을 막았다. 다만 이 바퀴를 **사람이 열었다.** 「언제 라운드를 열어야 하는가」는 아직 기계가 모른다 |
| 자기 적발력 | B | 오탐 2건과 유료 주행 1건을 **스스로** 잡았지만, 셋 다 **그 도구를 막 만든 직후에** 잡혔다. 이미 있는 도구가 조용히 틀리고 있는 자리는 여전히 안 세어 봤다 — 관측 법칙 §7 의 재는 법이 `argv.ts` 한 곳에만 붙어 있다 |

## 다음 단계

성운으로 올라간 것을 다음 바퀴에서 꺼낸다. 이번 바퀴가 남긴 것은 넷이다 —
3차 팽창이 만든 기능에 테스트가 안 생기는 구멍, 없는 플래그를 삼키는 자리를 안 세어 본 것,
그리고 위 평가의 **루프 완결성 B**(바퀴를 사람이 연다)와 **자기 적발력 B**.
