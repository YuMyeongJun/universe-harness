# R84 — README 가 시키는 대로 하면 되는가

## 실행 요약

R52~R55 가 `docs/` 를 실행 검증했는데 **README 는 안 봤다.** 가장 먼저 읽히는 문서다.
실행 가능한 명령은 **0줄**이었다(108줄 전부 설명). 그래서 **주장**을 봤다.

## 결과

### ⛔ 여덟 판 동안 낡아 있었다

```
## 상태
**v0.1.0 — 뼈대와 법칙 초판만 있다.** 아직 빅뱅도 관측소도 붙지 않았다.
| P2 관측소 연결 | ⬜ |   | P3 빅뱅 1차 팽창 | ⬜ |   | P4 플러그인화 | ⬜ |
```

실제: **판 0.9.0** · 빅뱅은 진짜 저장소에서 별을 낳고 · 관측소는 은하 넷을 재고 ·
배달은 단일 앱과 모노레포 둘에 됐다.

**이 저장소를 받은 사람이 가장 먼저 읽는 자리가 「아무것도 안 된다」고 말하고 있었다.**
지금까지 찾은 문서 결함 중 가장 크다 — 틀린 내용 때문이 아니라 **읽히는 자리**여서다.

### 고친 방식 — 세는 것은 생성하고, 판단은 근거를 요구한다

R55 의 처방을 넓혔다. `universe facts` 가 이제 **문서 두 편**(04-results · README)의
`<!-- FACTS -->` 블록을 채운다. **판도 그 블록에 넣었다** — 이번에 낡은 것이 판이었으니.

⛔ 단계 표는 **손으로 적는다.** 「됐다/안 됐다」는 판단이고 기계가 못 짚는다.
대신 **근거 칸을 만들었다 — 근거가 없으면 ✅ 를 못 적는다.**

⚠️ 2차 팽창(자가 수정)과 3차 팽창은 **🟡 로 남겼다.**
도는 것은 확인했지만 자가 수정은 한 번도 안 돌렸고, 3차는 진짜 은하에서 안 돌렸다 —
**돈이 없어 못 한 것은 못 한 것이다.**
