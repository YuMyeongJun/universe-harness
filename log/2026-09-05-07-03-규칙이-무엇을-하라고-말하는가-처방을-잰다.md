# R35 — 규칙이 무엇을 하라고 말하는가 — 처방을 잰다

## 실행 요약

규칙은 두 가지를 말할 수 있다. **「이건 틀렸다」**와 **「이렇게 해라」**.
앞엣것만 있으면 관문은 「고쳐라」가 아니라 「어쩌라고」가 되고, 사람은 고치는 법이 아니라
**관문을 무시하는 법부터 배운다**(`rules/tailwind.ts` R25 주석).
지금까지 어떤 검사도 뒤엣것을 재지 않았다 — 재고, 관문으로 남겼다.

**추출을 세 번 틀렸다.** ① 규칙 경계를 넘는 탐욕적 정규식이 `no-enum` 에 `arrow-only` 의
문구를 짝지었다. ② 처방 안의 백틱이 문자열 끝으로 읽혀 14개가 「없음」으로 보였다.
③ `fix:` 키만 훑어 `copy-state` 를 「처방 없음」이라 잘못 짚었다 — 그 규칙은 처방을
`findAll(..., 'rule/id', '처방')` 의 **위치 인자**로 넘긴다. 셋째가 §9 그 자체다:
**키 이름 하나를 열거한 훑개는 그 이름을 안 쓰는 자리에 눈이 먼다.**

## 결과

**고친 처방 4개** — 전부 「규칙의 되풀이」였던 것을 **전후 코드**로 바꿨다.

| 규칙 | 전 | 후 |
|------|----|----|
| `repo/arrow-only` | 모든 함수는 화살표 함수다. | `` `function go() {}` `` → `` `const go = () => {}` `` + 이유(호이스팅) |
| `repo/braces-required` | 모든 조건문에 `{}` 를 쓴다. | `` `if (x) return;` `` → `` `if (x) { return; }` `` + 이유(새어 나감) |
| `repo/interface-prefix` | 인터페이스 이름은 `I` 접두사다 (`IUserProps`). | `` `interface UserProps` `` → `` `interface IUserProps` `` |
| `tailwind/theme-hardcoded` | raw hex 금지 — 토큰으로. | `` `text-[#333]` `` → `` `text-foreground` `` |

**새 관문 — `universe fix`** (`observatory/verify-fix.mjs` · `observatory/fix-baseline.json`).

⛔ **정규식으로 「좋은 처방」을 판정하려다 두 번 실패했다.** 「백틱이 있어야 한다」는
`no-class`(“팩토리 함수나 훅으로 바꿔라”)를 틀렸다 했고, 「명령형 어미여야 한다」는
`img-alt`(“`alt` 를 반드시 준다”)를 틀렸다 했다. ⇒ 이름 충돌(R22)·열거(R34)와 **같은 방식**을
썼다: **사람이 판단하고 기준선에 적는다.** 목표는 「나쁜 처방 0개」가 아니라
**「판단하지 않은 처방 0개」**다. 규칙 20개 전부 판단을 적었다.

기준선은 처방 **문구 사본**을 들고 있다. 문구가 바뀌면 사본과 달라져 **판단이 자동으로 낡는다** —
문구를 나쁘게 고쳐도 판단이 「좋다」로 남는 구멍을 막는다.

**변이 시험에 2건 추가**(검사 6종·변이 10건 → **7종·12건**): 처방을 지우면 물고,
문구만 바꿔도 문다. 둘 다 실측으로 확인했다(exit 1 · 복원 후 exit 0).

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | 통과 | `round close` 게이트와 `universe checks` 변이 2건에 걸었다. 처방 삭제·문구 변경 각각 exit 1, 복원 후 exit 0 을 직접 재서 확인했다 |
| 실측 기반성 | 통과 | 20개 처방을 원본에서 뽑아 전수로 읽고 판단했다. 「좋은 처방 판정 정규식」은 두 후보 모두 오탐이 나와 **채택하지 않았다** — 재 보고 버렸다 |
| 변경 정직성 | 통과 | 추출을 세 번 틀린 것을 위에 그대로 적었다. 처방 4개는 「다듬었다」가 아니라 전/후를 표로 남겼다 |
