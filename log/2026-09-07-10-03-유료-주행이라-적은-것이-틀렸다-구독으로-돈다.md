# R140 — 유료 주행이라 적은 것이 틀렸다 — 구독으로 돈다

## 실행 요약

사용자가 물었다 — 「2차 팽창 **유료 에이전트**는 무슨 뜻이야, **내장 클로드로 안 되나**」.
재 봤다. **내 말이 틀렸다.**

## 결과

```
callClaude → spawn('claude', ['-p', '--system-prompt-file', …])
             ANTHROPIC_API_KEY 가 있을 때만 claude 쪽 bare 모드를 켠다
```

| | 실측 |
|---|---|
| `claude` CLI | **`/opt/homebrew/bin/claude` 2.1.236** — 있다 |
| `ANTHROPIC_API_KEY` | **없다** → **구독 경로** |

⛔ **엔진은 별도 API 호출을 하지 않는다.** 사용자가 이미 쓰는 **Claude Code CLI 를 그대로 부른다.**
내가 로그 **14곳**에 적은 「유료 주행이라 돈이 든다」는 **부정확했다** —
정확히는 「**그 기계의 구독 사용량을 쓴다**」다.

⚠️⚠️ **이 구분이 왜 중요한가.** 「돈이 든다」면 **안 하는 것이 옳다.**
「사용량을 쓴다」면 **물어보고 하는 것이 옳다.**
**틀린 이유로 안 하면 영영 안 한다** — 2차 팽창이 이 세션 내내 그 자리에 있었다.

**로그는 안 고쳤다.** 그때의 기록이고 라운드 번호가 붙는다(R124 에서 정한 것과 같다).
**지금 사실이 사는 자리**(문서·관문 주석)에 적고, **기계가 재게** 했다 —
엔진이 CLI 를 안 부르게 되거나 문서가 「유료」로 돌아가면 부품 시험이 문다.

⚠️ 닫는 길에 인자 관문이 물었다 — 내 문장의 `--bare` 를 **우주의 플래그**로 읽었다.
`claude` 쪽 모드라고 고쳐 적었다. **남의 도구 플래그를 우리 것처럼 적으면 오해가 된다.**

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | 통과 | CLI 호출이 사라지거나 문서가 「유료」로 돌아가면 문다 |
| 실측 기반성 | 통과 | CLI 경로·버전·키 유무를 실제로 봤다 |
| 변경 정직성 | 통과 | **내가 14곳에 틀린 말을 적었다**고 그대로 적었다 |

  픽스처(작다)부터 물어보고 돌리는 것이 순서다.
