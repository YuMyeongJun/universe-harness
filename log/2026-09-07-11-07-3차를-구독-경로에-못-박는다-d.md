## 잰 것

「3차는 유료라 못 돌린다」가 이 우주에서 가장 오래 산 미검증의 이유였다. **코드를 읽으니
이미 구독이었다** — `claudeCli.ts` 는 `ANTHROPIC_API_KEY` 가 **있을 때만** `--bare` 를 붙이고,
이 기계엔 키가 없다. 그런데 **아무것도 그것을 보증하지 않았다.**

| 잰 것 | 결과 |
|------|------|
| 모델을 부르는 자리 | 4곳(`runner.ts` · `contract.ts` · `wiki/extract.ts` · `nebula.mjs`)이 **전부 `callClaude` 하나로 모인다** — 목구멍이 하나다 |
| `spawn` 이 환경을 어떻게 넘기나 | ⛔ **`env` 를 안 넘긴다** — 자식이 부모 환경을 통째로 물려받는다 |
| 어느 경로로 돌았는지 말하나 | ⛔ **말하지 않는다** |

⇒ 키가 어디선가 새어 들어온 날 **아무 말 없이 과금 경로로 갈아탄다.** 모드가 바뀌는데
아무도 안 재는 자리였다(§8). 「지금은 구독이다」와 「구독으로만 돈다」는 다른 말이다.

## 고친 것 — 목구멍 하나

```ts
const { ANTHROPIC_API_KEY: droppedKey, ...childEnv } = process.env;
const child = spawn(bin, args, { env: childEnv, stdio: ['pipe', 'pipe', 'inherit'] });
```

`--bare` 분기는 **지웠다.** 키가 자식에 없으므로 `--bare` 는 이제 언제나 틀린 선택이다
(원 주석의 실측: 키 없이 `--bare` 를 붙이면 `terminal_reason: "api_error"` 로 **조용히 빈 결과**).
그리고 주행 첫 줄에 **한 번만** 말한다: `🔑 인증 — 구독 경로 (ANTHROPIC_API_KEY 를 자식에서 지웠다)`.

## 반증 — 소스를 읽는 것으로는 부족하다

⛔ **가짜 키를 넣고 3차를 진짜로 태웠다.** 키가 자식에 갔다면 인증 실패로 죽는다.

```
ANTHROPIC_API_KEY=sk-ant-INVALID-KEY-R145 node bigbang/bigbang.mjs new tiny-galaxy shop KeyProbe --from "상품 개수를 보여 주는 배지"
→ exit 0 · 턴 7 · 게이트 1 · [SOLVED]
→ 🔑 인증 — 구독 경로 (ANTHROPIC_API_KEY 를 자식에서 지웠다)
```

**완주했다.** 이것이 구독 경로의 유일한 증거다 — 소스 검사는 「그렇게 적혀 있다」까지만 잰다.

## 덤 — 이 반증이 **C1 을 겸했다**

계획의 C1(픽스처 3차 실주행)이 요구한 것을 그대로 만족했다:

| C1·C2 기준 | 실측 |
|------------|------|
| 궤적에 `nebula-end` | ⭕ 있다 |
| 궤적에 `requirement-signal` | ⭕ 있다 — **R132 가 「호출 자리만 셌다」고 남긴 그 자리가 실제로 돌았다** |
| 별이 게이트를 지난다 | ⭕ lint 0 · build 0 · test 0 · `[SOLVED]` |

궤적 17줄: `nebula-start=1 · action=7 · probe=5 · contract=1 · gate=1 · requirement-signal=1 · nebula-end=1`

신호는 `missing: []` 라 했고 **맞는 말이었다** — 요구사항의 낱말이 코드에 실제로 있다
(상품 2 · 개수 5 · 배지 5). ⚠️ 그래도 **낱말이 있는 것이 충족은 아니다**(R130).
처음엔 내 `grep` 이 「개수·배지가 없다」고 했는데 **틀린 쪽은 grep 이었다**(정규식 대안 표기).

## 건 것 — 검사 하나, 변이 셋

`lib/selftest.mjs` 가 **소스와 dist 둘 다** 잰다. 소스만 재면 빌드를 잊었을 때 도는 것은 옛 코드다.

| 변이 | 문 말 |
|------|-------|
| 소스에 `--bare` 부활 + 빌드 | 「src/…claudeCli.ts 이 `--bare` 를 민다 — 그 갈래는 API 키로만 인증한다」 |
| `spawn` 에서 `env` 제거 + 빌드 | 「`spawn` 에 env 를 안 넘긴다 — 자식이 부모의 ANTHROPIC_API_KEY 를 물려받는다」 |
| dist 만 낡게 | 「dist/…claudeCli.js 이 `spawn` 에 env 를 안 넘긴다」 |

⚠️ 앞의 둘을 **빌드 없이** 변이시키면 **빌드 도장 검사가 먼저** 문다 — 「dist 가 지금 소스에서
나온 것이 아니다」. 그쪽이 더 정확한 말이라 그대로 뒀다. 그래서 내 검사를 진짜로 시험하려면
**고치고 빌드까지** 해야 했다. 변이 시험도 재는 대상을 정확히 겨눠야 한다.

⚠️ **분모 검사(`laneChecked === 2`)는 실전에서 도달하지 않는다.** dist 파일을 치워 보니
다른 검사가 먼저 물었다(끊김 검사). 죽은 건 아니지만 **이 검사가 지키는 자리는 아니다** — 적어 둔다.

## 못 잰 것

- **다른 기계에서도 구독인지**는 못 잰다 — 그 기계의 로그인 상태다. 여기서 잰 것은
  **「우리가 키를 안 넘긴다」**까지다.
- `apiKeyHelper` 로 키를 공급하는 설정은 **안 재 봤다.** 자식 env 에서 지우는 것만으로
  막히는지 확인하지 않았다.
