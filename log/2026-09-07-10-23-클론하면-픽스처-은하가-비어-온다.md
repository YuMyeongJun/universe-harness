## 잰 것

저장소를 옮기고 `git init` 으로 이력을 새로 시작한 뒤, **클론이 정말 도는지** 처음 쟀다.
세 가지가 나왔고 셋 다 초록불 뒤에 숨어 있었다.

| 잰 것 | 결과 |
|------|------|
| 클론의 픽스처 은하 | ⛔ **비어 온다** — 중첩 저장소라 `git add` 가 gitlink 한 줄로 접었다 |
| 클론에서 부품 시험 | ⛔ **원본 저장소의 픽스처가 고쳐졌다** — 좌표가 절대 경로였다 |
| 은하가 선언한 명령 | ⛔ `npm run typecheck` 가 픽스처에 **없었다** |

### 1. 클론하면 픽스처가 비어 온다

`fixtures/tiny-galaxy` 는 자체 `.git` 을 가진다(워크트리 샌드박스에 필요 — `fixtures/README.md`).
그래서 바깥 저장소의 `git add` 는 파일 17개가 아니라 **gitlink 한 줄**을 담았다.
옛 저장소에서 되던 이유는 파일이 **안쪽 `.git` 이 생기기 전에** 이미 색인에 있었기 때문이다.
안쪽 `.git` 을 잠시 치우고 `git add` 해 같은 상태를 만들었다.

⚠️ `fixtures/README.md` 는 「바깥이 픽스처 파일 **전부**를 추적해 클론하면 바로 돌게」라고
적어 뒀다 — **문서는 맞았고 저장소가 틀렸다.** 문서가 있어도 재지 않으면 어긋난다.

### 2. 절대 좌표가 저장소 경계를 넘었다

클론에서 `bin/check.mjs` 를 돌렸더니 **원본**의 `fixtures/tiny-galaxy/package.json` 이 고쳐져
있었다. 클론의 `galaxies/tiny-galaxy.json` 이 `/Users/.../universe-harness/fixtures/tiny-galaxy`
를 그대로 가리켰기 때문이다. 클론은 제 사본이 아니라 **원본을 물었다.**

고침: 저장소 **안**의 은하는 상대 경로로 적고, `lib/galaxy-load.mjs` 가 우주 뿌리 기준으로 푼다.
입구가 하나뿐이라 한 자리만 고치면 됐다. 절대 경로는 **남의 저장소**(진짜 은하)에만 쓴다.

### 3. 선언한 명령이 실재하지 않았다 — 그리고 **별을 탓했다**

`galaxies/tiny-galaxy.json` 이 `npm run typecheck` 를 선언하는데 픽스처 package.json 에
그 스크립트가 없었다. 컴파일 관문이 `Missing script: "typecheck"` 로 죽었고, 빅뱅은 그것을

> ⛔ **별이 은하에서 서지 않는다** (exit 1)

로 보고했다. **별은 멀쩡했다.** 못 쟀는데 판정을 냈다(§8) — 이번엔 엉뚱한 피고를 세운 꼴로.

⚠️ 나는 이 변경을 처음에 **클론이 낸 상처로 읽고 되돌렸다.** 되돌리자 관문이 죽었다.
「낯선 변경 = 오염」이 아니었다 — 커밋되지 않은 채 작업 트리에만 살던 **정상 상태**였다.
픽스처 안쪽 저장소에 커밋해 다음 클론부터는 따라오게 했다.

## 건 것 — 검사 넷, 변이 넷

`lib/selftest.mjs`:

| 검사 | 변이 | 문 말 |
|------|------|-------|
| 좌표가 실재하는 자리를 가리키나 | `path` 를 없는 폴더로 | 「없는 자리를 가리킨다 — 저장소를 옮겼나」 |
| 안쪽 은하가 상대 경로인가 | 절대 경로로 되돌림 | 「클론이 원본을 문다 — 상대로 적어라」 |
| 선언한 npm 명령이 실재하나 | `npm run nonexistent` | 「없는 명령을 선언했다 — 관문이 죽으면 별을 탓하게 된다」 |
| 분모 (npm 명령 ≥ 3) | npm 명령을 전부 제거 | 「0개밖에 못 찾았다 — 검사가 죽었나(§8)」 |

⚠️ 명령 검사는 `npm run <이름>` 꼴만 잰다 — `npx`·복합 셸 명령은 **못 판별한다.** 그렇게 적었다.

## 순서를 옮겼다 (R137 재발)

처음 변이를 쟀을 때 변이 1·2가 **안 물었다.** 죽어서가 아니라 **끊김 검사가 먼저 빨개져서**였다
— 그 검사가 은하를 실제로 태우기 때문이다. 첫 빨간 줄이 「별이 남았다」였고, 그건 원인이 아니다.
좌표·명령 블록을 은하를 태우는 첫 검사보다 **앞으로** 옮겼다. 이제 넷 다 제 이름으로 문다.

**검사는 걸리는 것만으로 부족하다 — 먼저 걸려야 원인을 짚는다.**

## 덤: 갓 클론한 자리에서 또 별을 탓했다

끊김 검사가 클론에서 빨갰다. 엔진 **소스는 배달되고 빌드는 안 된다** — 빅뱅이 별을 만들기 전에
「엔진을 빌드하라」로 나가는데, 검사는 그것을 「지웠다는 말을 안 했다」로 읽었다.
빌드 여부를 조건으로 걸고 없으면 **못 쟀다고 말하게** 했다.

## 남긴 것

- 진짜 은하(`backoffice`)는 여전히 절대 경로다 — **맞다.** 남의 저장소는 이 우주와 함께 옮겨 다니지 않는다.
- 첫 커밋이 섰다. ⚠️ **옛 자리의 커밋 101개는 이 원격에 없다** — 파일과 라운드 로그는 전부 살아 있고 이력만 새로 시작한다.
