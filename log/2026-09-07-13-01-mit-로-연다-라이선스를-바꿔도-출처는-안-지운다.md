# R150 — MIT 로 연다 — 라이선스를 바꿔도 출처는 안 지운다

## 실행 요약

사용자가 **MIT 로 공개**를 정했다(2026-09-07). 0.10 「범용화」 주제의 첫 칸이다.
들어갈 때 셋이 어긋나 있었다: `license: "UNLICENSED"` · `private: true` · **LICENSE 파일 없음.**

## 결과

### 고친 것

| 자리 | 전 | 후 |
|------|----|----|
| `LICENSE` | **없음** | MIT · `Copyright (c) 2026 YuMyeongJun` |
| `package.json` `license` | `UNLICENSED` | `MIT` |
| `package.json` `private` | `true` | **뺐다** |
| `package.json` `repository` | 없음 | `github.com/YuMyeongJun/universe-harness` |
| `package.json` `files` | LICENSE 없음 | **LICENSE 추가** |

### MIT 의 유일한 조건을 **배달본으로** 확인했다

MIT 가 요구하는 것은 하나다 — 「이 고지를 사본에 포함하라」.
LICENSE 를 저장소에만 두고 `files` 에 안 넣으면 **배달본에는 안 실린다.** 조건을 어긴 채 배포된다.

```
$ npm pack --dry-run
배달본 파일 수: 86 · 641KB
LICENSE 실렸나: True
은하/성운/로그가 실렸나: 없다 ✅ (보존 법칙 그대로)
```

⇒ **파일을 만든 것으로 끝내지 않고 배달본을 열어 봤다.** `files` 배열을 눈으로 읽는 것과
`npm pack` 이 실제로 담는 것은 다르다(「원본이 도는 것과 배달본이 도는 것은 다르다」 — 42커밋 동안 달랐던 그 자리).

### ⛔ 라이선스를 바꾼다고 출처가 사라지지 않는다

`docs/06-credits.md` 는 EnvHarness(Apache 2.0)·카카시 하네스(MIT)를 **설계 채택**으로 밝히고
있고 「코드를 가져오지 않았다」고 적혀 있다. 코드를 안 가져왔으므로 라이선스 **의무**는 없다.
그래도 고지는 **유지한다** — 의무가 없는 것과 밝히지 않아도 되는 것은 다르다.
그래서 부품 시험이 그 두 줄을 **지우면 문다.**

### 일부러 깨서 무는지 봤다

| 변이 | 물었나 |
|------|--------|
| `files` 에서 `LICENSE` 를 뺀다 | ✅ 「배달본에 안 실려 MIT 조건을 어긴다」 |
| 출처 고지에서 `Apache 2.0` 을 지운다 | ✅ 「출처 고지에서 EnvHarness 의 라이선스가 사라졌다」 |

## 평가

| 축 | 판정 | 근거 |

| 집행 가능성 | A | 여섯 단언을 부품 시험에 박고 변이 둘로 물림 확인. `license` 문자열만 보는 것이 아니라 **배달본에 실리는지**까지 잰다 |
| 실측 기반성 | A | `npm pack --dry-run` 으로 86개 파일 목록을 실제로 열어 LICENSE 를 확인했다. 「files 에 적었으니 실릴 것이다」로 닫지 않았다 |
| 변경 정직성 | A | 저작권자를 **GitHub 계정 이름 그대로**(`YuMyeongJun`) 적었다 — 로마자 표기를 짐작하지 않았다. 사람이 고칠 자리라고 아래에 적어 둔다 |

## 다음 단계

- ⚠️ **저작권자 이름은 사람이 확인해야 한다.** `YuMyeongJun`(GitHub 계정)을 그대로 썼다 —
  법적 이름이나 다른 표기를 원하면 `LICENSE` 한 줄이다. 짐작으로 로마자를 만들지 않았다.
- ⚠️ `private` 를 뺐으므로 **`npm publish` 가 기술적으로 가능해졌다.** ⛔ 하지 않았다 —
  배포는 사용자가 시킬 때만 한다.
