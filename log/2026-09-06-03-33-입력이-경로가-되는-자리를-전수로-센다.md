# R77 — 입력이 경로가 되는 자리를 전수로 센다

## 실행 요약

R76 이 은하 이름의 경로 탈출을 막았다. **하나만 막고 끝내면 나머지가 남는다** — 전수로 셌다.

| 자리 | 결과 |
|------|------|
| `galaxy <이름>` | ✅ R76 에서 막았다 |
| `new <별 이름>` | ✅ PascalCase 로 막혀 있었다 |
| `--out` | 사람이 **일부러** 자리를 정하는 것 — 막지 않는다 |
| `init --dir` | ⛔ **저장소 밖에 깔린다** |
| `observe --galaxy` | ⛔ **오타를 삼키고 초록불** |

## 결과

### ⛔ 오타 하나에 「기준선이 실측과 같다」가 떴다

```
universe observe --galaxy tiny-galexy
  ⚠️ 은하 tiny-galexy — 좌표 파일이 없다. 실측을 건너뛴다.
✅ 법칙이 규칙을 빠짐없이 덮고, 은하의 기준선이 실측과 같다.   ← 종료코드 0
```

**잰 것이 하나도 없는데 초록불이다.** 관측 법칙 §8 그대로다.

⚠️ 좌표 파일이 없는 은하를 건너뛰는 관용은 **config 에 이름만 올라간 상태(영입 전)**를 위한 것이다.
그런데 **사람이 이름을 짚어 물었을 때**는 그 관용이 거짓말이 된다.

⇒ §7 이 모르는 **플래그**에 하는 답을 모르는 **이름**에도 한다.

```
⛔ 그런 은하가 없다: 없는은하
   아는 은하는 이것뿐이다: tiny-galaxy · messy-galaxy
```

`lint`·`speed` 도 같은 답을 하게 맞췄다 — 오타를 낸 사람이 **어디서 물어도 같은 답**을 들어야 한다.

### ⛔ `init --dir ../탈출우주` 가 저장소 밖에 깔았다

커밋 관문(`core.hooksPath`)도, 「`universe/` 를 git 에 올려라」는 안내도, 배달본 갱신도
**전부 이 저장소를 전제**한다. 밖에 깔리면 **조용히 다 어긋난다.**

⛔ **막지는 않았다** — 일부러 그러는 사람이 있을 수 있다(R65 의 규율).
**조용히 지나가지 못하게** 했다.

**변이 23종·28건 → 24종·29건.**

## 평가

| 축 | 판정 | 근거 |
|----|------|------|
| 집행 가능성 | 통과 | 오타 삼킴을 변이로 박았다(config 의 이름을 틀리면 exit 1). `--dir` 경고는 보고이며 그렇게 적는다 |
| 실측 기반성 | 통과 | 다섯 자리를 하나씩 실제로 쳐 봤다. 밖에 깔린 우주는 **폴더가 생긴 것을 눈으로 확인**하고 지웠다 |
| 변경 정직성 | 통과 | 막지 않은 둘(`--out` · `--dir`)과 **왜 안 막았는지**를 적었다. 이미 막혀 있던 둘도 그렇다고 적었다 |
