# R151 — 전파를 git 위키로 옮긴다 — 좌표가 없어지고 검사가 혼자 돌게 됐다

## 실행 요약

사용자가 「깃허브 기능을 최대한 쓰자」고 했다. 재 보니 **위키가 성운 셋과 `NOT_GATED` 하나를
동시에 붙들고 있었다.** 원인이 하나였다 — 전파 대상이 **git 이 아니었다.**

## 결과

### 하나를 옮겼더니 넷이 풀렸다

| 붙들려 있던 것 | 왜 그랬나 | 지금 |
|---|---|---|
| **R17** 자동화 완결성 | 「이 검사는 **혼자 못 돈다** — Confluence 는 MCP 로만 읽히고 스크립트의 손이 안 닿는다」 | git 위키는 **clone 된다.** 스스로 가져와 대조한다 |
| **R07** 전파 정합성 | 「위키 **본문을 읽지 않는다**」 | 읽는다 |
| 왕복 정규화 **여섯 패턴** | v2 REST 가 본문을 XHTML 로만 받아 표 구분선·불릿·이스케이프가 바뀌었다 | **필요 없다** — git 은 바이트를 그대로 들고 있다(실측: 7장 전부 정규화 없이 동일) |
| 커밋된 **사내 좌표** | 사이트 · 스페이스 키 · 페이지 id 일곱 | **없다** — 주소를 `origin` 에서 파생한다 |

⚠️ **R18 은 절반만** 풀린다. mermaid 는 GitHub 이 그대로 렌더하니 풀리고,
**SVG 상대 경로는 그대로 안 뜬다.** 절반이라고 적는다.

### 좌표를 적지 않는다 — 파생한다

`lib/wiki-remote.mjs` 가 `git remote get-url origin` 에서 위키 주소를 뽑는다.
⇒ **적을 좌표가 없다.** 포크한 사람은 자기 위키로, 원본은 원본 위키로 자동으로 간다.

```
https://github.com/o/r.git          → https://github.com/o/r.wiki.git
git@github.com:o/r.git              → https://github.com/o/r.wiki.git   (ssh 짧은 형식도 편다)
https://gitlab.com/o/r.git          → null   ⛔ 모르는 호스트에 주소를 지어내지 않는다(§9)
https://user:ghp_…@github.com/o/r   → 자격증명을 **떼고** 세운다 (주소는 화면과 로그에 찍힌다)
```

### 없어진 것이 성과다

`beacon/wiki.mjs` 에는 **마크다운→XHTML 변환기가 없다.** Confluence 쪽 `publish.mjs` 는
그 변환기를 직접 들고 있었다(v2 REST 가 `storage` 로만 받아서). git 위키는 마크다운을
그대로 담으므로 변환할 것이 없다. **정규화층도 같이 사라졌다** — 그 층은 원래
「**진짜 사람 수정이 가장 쉽게 숨는 곳**」이었다.

### 실측 — 진짜 git 위키에 왕복시켰다

GitHub 위키는 **그냥 git 저장소**라, 로컬 bare 저장소가 충실한 대역이다(호스팅만 빠진다).

```
$ node beacon/wiki.mjs --remote <로컬 bare> --push
   + forces.md … + rounds.md   (7장)  ✅ 발행했다

$ 다시 클론해서 정규화 **없이** diff
   (7장 전부 바이트 동일)
```

검사 넷을 양방향으로 쟀다:

| 잰 것 | 결과 |
|---|---|
| 같으면 통과하는가 | ✅ 7장 통과 |
| 위키를 **손으로 고치면 무는가** | ✅ 「손으로 고쳐진 장 1개」 · exit 1 |
| 위키가 **없을 때** | ✅ **「못 쟀다」 · exit 0** — 실패가 아니다(§8) |
| GitHub 아닌 origin | ✅ 「주소를 지어내지 않는다」 |

### Q4 — 커밋된 사내 좌표를 걷어냈다

| 자리 | 전 | 후 |
|---|---|---|
| `universe.config.json` 의 `beacon` 블록 | 사이트·스페이스 키·스페이스 이름·pageId | **뺐다** (코드가 아무도 안 읽던 죽은 좌표였다) |
| `beacon/pages.json` | 사이트·스페이스 키·**페이지 id 일곱** | 장 **이름표만** 남겼다 |
| Confluence 좌표 | 커밋돼 있었다 | `.secret/confluence-pages.json`(gitignore)로 **옮겨 보관** |

⛔ **Confluence 발행을 부수지 않았다.** `publish.mjs` 가 `.secret` 을 먼저 읽어서
좌표가 있으면 예전 그대로 돈다(실측: dry-run 이 페이지 id 일곱을 그대로 찍는다).
쓰던 길을 말없이 끊지 않는다.

### 관문에는 **아직** 안 넣었다 — 사유를 바꿨다

`NOT_GATED` 의 사유를 고쳤다. 예전 사유(「MCP 로만 읽혀 혼자 못 돈다」)는 **이제 거짓**이다.
새 사유는 다르다: **네트워크가 필요하고 위키가 한 번은 만들어져 있어야 한다.**
갓 클론한 우주·오프라인 CI 에서는 「못 쟀다」로 지나가므로, 넣으면 **재는 척만 하게 된다.**
⚠️ 낡은 사유를 그대로 두는 것도 결함이다 — 다음 사람이 「아직도 MCP 때문」인 줄 안다.

### 일부러 깨서 무는지 봤다

| 변이 | 물었나 |
|------|--------|
| 모르는 호스트에도 위키 주소를 지어낸다 | ✅ 「GitLab 위키 주소를 지어냈다」 |
| origin 을 그대로 물려준다(자격증명 누수) | ✅ 「자격증명이 위키 주소로 새어 나간다」 |
| 위키를 손으로 고친다 | ✅ 「손으로 고쳐진 장 1개」 |

⚠️ 둘째는 **조준을 다시 했다.** 첫 변이(`raw` 를 그대로 씀)는 **ssh 갈래가 먼저** 물어서
자격증명 누수를 시험한 것이 아니었다. https 만 자격증명을 물려주도록 좁혀서 다시 쟀다.
R143·R145·R146·R148·R149 에 이어 **다섯 번째**다.

|----|------|------|
| 집행 가능성 | A | 부품 시험에 여섯 단언 + 변이 셋. 다만 **관문에는 못 넣었다** — 넣으면 네트워크 없는 곳에서 재는 척만 한다. 사유를 적고 뺐다 |

| 변경 정직성 | A+ | R18 이 **절반만** 풀린 것을 적었다(SVG 상대 경로는 그대로다). 낡은 `NOT_GATED` 사유를 고쳤다 — 사유가 낡는 것도 결함이라고 적었다. 조준 실패도 적었다 |
