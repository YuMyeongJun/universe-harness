# 우주 (Universe)

> 빅뱅 한 번으로 별이 태어난다. 그리고 **태어난 별은 법칙을 지킨다.**

**자동 트리거 금지** — `/universe` 로만 활성화한다.

---

## 0. 먼저 확인할 것 (최우선)

활성화되면 **먼저 우주가 깔려 있는지 확인**한다.

```bash
universe laws
```

- **「우주를 찾지 못했다」** → §1 설치 안내
- **초록불** → §2 로 진행. 그리고 `universe.config.json` 을 읽어 법칙·은하 현황을 파악한다

⛔ 우주를 찾지 못했는데 **패키지 안의 법칙을 읽어 답하지 마라.** 그것은 소비 저장소의 상태가 아니다.

---

## 1. 설치

```bash
npx universe-front-harness init   # <저장소>/universe/ 를 깐다
```

깔리는 것: **법칙 · 궤도 · 힘 · 빅뱅 · 관측소 · 문서**
빈 틀로 만드는 것: **은하 · 로그** — 그것은 그 저장소의 것이라 배달되지 않는다

그다음 **은하를 등록**해야 한다(`universe/examples/galaxy.example.jsonc` 를 베낀다).
은하 = 법칙이 적용되는 저장소 하나. 우주는 별을 갖지 않고 **좌표만** 들고 있다.

---

## 2. 명령

| 사용자가 말하면 | 부를 것 |
|---|---|
| "관측해" · "위반 몇 건" · "법칙 검사" | `universe observe` |
| "기준선 심어" | `universe observe --update` |
| "검증해" · "게이트 돌려" | `universe verify --galaxy <은하>` |
| "별 만들어" · "화면 만들어" | `universe new <은하> <태양계> <별>` |
| "우주 검사" | `universe laws` |
| "발행해" | `universe render` → `universe publish` |

⛔ **게이트를 반복해서 직접 돌리지 마라.** 타입 인지 lint 저장소에서 동시 실행하면
`eslint ./src` 가 10.3초 → 21분이 된다(실측). 검증이 필요하면 `universe verify` 를 **한 번** 부른다.

⛔ **검사 결과를 파이프 뒤에서 판정하지 마라.** `cmd | tail` 의 종료코드는 마지막 명령의 것이라
**실패가 0으로 보인다.** 그리고 출력을 걸러 보면 **크래시 자체를 놓친다**(실측 2회).
파이프 없이 돌리고, 전체 출력을 지나간 뒤에 요약하라.

---

## 3. 사용자가 「고쳐줘」라고 할 때

관측이 낸 위반을 고치는 것은 **당신의 일이다.** 다만 순서가 있다.

1. **한 법칙씩** 고친다. 다섯 법칙을 한 번에 손대면 무엇이 무엇을 고쳤는지 모른다.
2. **표본을 먼저 보라** — `universe observe --law <법칙> --sample 20`.
   ⚠️ **오탐일 수 있다.** 이 우주의 규칙들은 실측에서 오탐 4종·153건이 드러난 이력이 있고,
   그중 가장 나빴던 것은 관문이 **지키라는 것을 지킨 코드를 벌하는 것**이었다.
   오탐이면 코드를 비틀지 말고 **법칙을 고치라고 보고하라.**
3. 고친 뒤 `universe verify` 로 확인한다.
4. 위반 수가 줄었으면 `universe observe --update` 로 기준선을 내린다.

⛔ **기준선을 올려서 통과시키지 마라.** 그것은 통과가 아니다.

---

## 4. 법칙을 추가할 때

⚠️ **가장 자주 실패하는 일이다.** 절차를 건너뛰지 마라.

1. 규칙이 있는지 본다 → 없으면 만든다
2. **실제 은하에 걸어 표본을 눈으로 보고 오탐을 센다** ← 여기가 핵심
3. 오탐이 있으면 규칙을 고치고 **양방향 회귀**를 박는다(잡아야 할 것 + 잡으면 안 될 것)
4. `laws/{name}.md` — 규칙 / 왜 / **재는 법** / 위반 시. 「재는 법」이 없으면 법칙이 아니다
5. `universe.config.json` 등재 → 은하가 켠다

**작은 표본의 오탐 0 은 아무것도 보장하지 않는다.**
그리고 **0건은 무죄가 아니다** — 탐지가 약한 것일 수 있다(실측: 어떤 규칙이 0건을 냈는데
훑개로 바꾸자 같은 코드에서 21건이 나왔다).

법칙이 헛돌면 **뺀다.** 헛도는 관문은 무시하는 법부터 가르친다.

---

## 5. 라운드를 돌 때

작업이 끝나면 `universe/log/{yyyy-MM-dd-HH-mm}-{제목}.md` 에 남긴다.

**필수 절:** 실행 요약 · 결과 · **평가** · 다음 단계

평가 규칙:
- **축 / 판정 / 근거** 표로. **근거 없는 등급은 무효다**
- **합성 등급 금지** — "종합 B+" 로 합치지 않는다
- **정직성 축을 포함한다** — 안 한 것을 안 했다고 적었는가

그리고 **A 가 아닌 축은 성운으로 승격한다.**
⛔ 이것을 빠뜨리면 평가는 장식이다. **로그에만 남은 제안은 실행되지 않는다.**

---

## 6. 이 우주가 지키는 것

| 법칙 | 무엇 |
|------|------|
| **보존** | 지식은 우주 안, 별은 우주 밖. **은하의 코드를 고치지 않는다** |
| **중력** | 모든 문서는 최소 하나의 엣지 — 고아 금지 |
| **관측** | **잰 것만 사실이다.** 추정·인용은 사실이 아니다 |
| **광속** | 임계값은 깨끗한 상태의 실측값 이상 |
