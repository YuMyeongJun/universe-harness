# 지식 실측 콘솔

도메인 지식을 **사람이 클릭으로** 만드는 로컬 웹앱. 명령어를 외울 필요가 없다.

`qa-workflow` 의 `domains/{도메인}/knowledge/` 를 채우는 것이 목적이다.
채워진 도메인(해피톡·아이비플로우 …)과 **같은 형식**으로 낸다.

## 왜 있는가

`qa-workflow` 의 잡은 4종(`tc-execute` · `tc-write` · `knowledge-reflect` · `knowledge-apply`)이고,
**없는 지식을 처음 만들어내는 흐름이 없다.** 기존 지식 화면은 *문서를 넣으면* 반영안을 만들 뿐이라,
`callbridge` · `heythere` 처럼 `_TBD` 골격만 있는 도메인은 시작할 방법이 없었다.

이 앱이 그 자리를 메운다: **제품을 열어 → 걷고 → 사람이 확인 → md 로 낸다.**

## 띄우기

```bash
cd app/knowledge
npm install          # 최초 1회 (Chromium 도 함께 받는다)
npm run dev          # http://127.0.0.1:5174
```

> 루트 저장소의 `npm ci` · `npm test` · CI 는 이 앱을 받지 않는다. **관문 시간에 영향이 없다.**
> 이 앱은 자기 `node_modules` 를 따로 쓴다.

지식 저장소는 **형제 폴더**에서 찾는다 (`../qa-workflow-v2-main`). 다른 곳에 두었으면:

```bash
QA_WORKFLOW_DIR=../어디_다른_곳 npm run dev
```

## 네 걸음

| | 하는 일 | 왜 사람이 하나 |
|---|---|---|
| ① 진입점 | 주소 · 로그인 방식 · 계정 | **제품을 아는 사람만 안다.** 기계가 채울 수 없다 |
| ② 자동 수집 | 브라우저가 눈앞에 열린다. 로그인은 **직접** 하고, 도착한 화면에서 「지금 화면부터 수집」 | SSO·OTP 를 기계가 대신하려다 실패하면 **왜 실패했는지도 안 남는다** |
| ③ 사람이 교정 | 수집된 항목을 `확인함` / `고쳐서 확인` / `아님` | **수집됐다는 것과 맞다는 것은 다르다** |
| ④ 지식 생성 | 무엇을 쓸지 먼저 보여주고, 눌러야 쓴다 | 미리보기는 아무것도 쓰지 않는다 |

메뉴가 여러 화면에 흩어져 있으면 **화면을 옮겨 가며 여러 번** 수집한다.
이미 담긴 항목과 이름·URL 이 같으면 다시 담지 않고 **사람 판정도 보존**한다.

## 이 앱이 지키는 것

이 저장소의 규율(`tc-lint` 의 `0` / `1` / **`3` 못 쟀다`)을 지식 쪽에도 그대로 적용한다.

- **미확인은 미확인으로 적는다.** 확인 안 된 항목을 빼면 문서가 완성된 것처럼 보인다.
  그래서 `⚪ 아직 확인되지 않은 것` 절에 **이름을 달고 남는다** — 조용히 빠지지 않는다.
- **실측일과 「수집 대상 빌드」를 박는다.** 지식이 낡았다는 신호가 없으면 8월 문서와 어제 문서가
  똑같이 보인다. 날짜만으로도 부족하다 — **같은 날 걷어도 빌드가 다르면 화면이 다르다.**
  실제로 첫 실전에서 걷은 사본이 담당자의 브랜치가 아니었다.
- **못 쟀으면 실측일을 찍지 않는다.** 메뉴 후보 0건이나 본문이 얇은 화면(404·로그인 튕김)은
  「못 쟀다」로 떨어진다. **0건은 "메뉴가 없다"가 아니라 "못 봤다"** 이고,
  못 본 것에 날짜를 다는 것이 진짜 피해다. 도달 신호(본문 길이·입력·버튼 수)를 함께 잰다.
- **「말한 것」과 「잰 것」을 같은 칸에 넣지 않는다.** 사람이 누른 `확인함` 은 **주장**이지 측정이 아니다.
  생성 문서의 LNB 표는 🧑 로 표시되고, **누가·언제 판정했는지**가 함께 남는다(서버가 찍는다 — 화면이
  보낸 값은 버린다). 항목별 도달 증거는 **아직 없고, 없다고 문서에 적는다.**
- **계정 정보는 나가지 않는다.** 수집에만 쓰고, 문서에 섞이지 않았다는 것을 **나가기 전에 기계로 확인**한다.
  섞였으면 생성 자체가 막힌다.
- **사람이 쓴 문서를 덮지 않는다.** 골격(`_TBD`)이 아닌 기존 문서는 **체크해야만** 덮어쓴다.
- **초안은 커밋되지 않는다.** `.data/` 는 gitignore 된다 — 계정 정보가 들어 있다.

## 한계 — 아직 안 되는 것

- **한 번에 한 도메인.** 브라우저 세션이 하나다. 두 도메인을 섞으면 수집이 오염된다.
- **LNB 후보를 넓게 걷는다.** 앱마다 마크업이 달라 `nav`·`aside`·`[class*=lnb]` 등을 훑는다.
  광고 배너·도움말 같은 게 섞여 들어오므로 **③에서 `아님` 으로 걸러야 한다.** 그게 설계다.
- **항목별 도달 증거가 없다.** 도달 신호(본문 길이·요소 수)는 **스캔 단위**라 항목 하나하나를
  뒷받침하지 못한다. 스크린샷도 항목에 연결되지 않는다. 그래서 🧑 를 ✅ 로 승격하지 않는다.
- **`아님` 판정에 사유가 없다.** 사유가 없으면 「판단했다」가 아니라 「치웠다」에 가깝다.
- **`rules.md`(로그인 절차·대기 정책·실패 판정)는 아직 안 만든다.** `features.md` 와 `features/` 골격까지다.
- **로그인 상태로 열면 안 되는 화면**(로그인·가입·정보찾기 등)은 로그인 세션으로 열면 홈으로 튕긴다.
  그대로 걷으면 "이 화면들은 홈과 같다"는 지식이 생긴다. 지금은 **③에서 사람이 걸러야 한다.**
- **자체 서명 인증서**는 ①에서 켜야 열린다(기본 꺼짐). 로컬 dev 서버가 HTTPS 인 경우가 많다.
- ⚠️ 수집 시점 스크린샷에 **로그인 화면의 저장된 계정이 찍힐 수 있다.** `.data/` 는 커밋되지 않지만
  화면 공유 전에는 확인하라.
