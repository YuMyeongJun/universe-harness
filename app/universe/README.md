# 우주 콘솔

터미널 없이 **화면에서** 우주를 돌리는 로컬 웹앱. 명령어를 외울 필요가 없다.

## ⚠️⚠️ 이 문서는 통째로 다시 쓰였다 — 그 사실이 이 파일의 첫 내용이다

전에 여기 적혀 있던 것은 **다른 제품의 설명서**였다. 「도메인 지식을 사람이 클릭으로 만드는
로컬 웹앱」이라고 적혀 있었고, `qa-workflow` 의 `domains/{도메인}/knowledge/` 를 채우는 것이
목적이라고 했다. 띄우는 법마저 `cd app/knowledge` 였다 — **지금 없는 폴더다.**

이 콘솔은 `qa-harness` 에서 흡수돼 오면서 그 설명서를 함께 달고 왔고,
**화면은 우주로 바뀌는 동안 문서만 옛 제품에 남아 있었다.**
⛔ 그래서 고쳐 적은 것이 아니라 **버리고 다시 적었다.** 반쯤 맞는 문서는 틀린 문서보다 나쁘다 —
어디까지 믿어야 하는지를 읽는 사람이 매번 다시 판단해야 한다.

## 무엇을 하는가

이 저장소(`universe.config.json` · `galaxies/` · `galaxies.local/`)가 **정본**이고,
콘솔은 그것을 **읽고 · 재고 · 사람의 판정을 받아 적는** 자리다.

| 레일 | 하는 일 |
|---|---|
| **받아 오기** | 깃 주소를 받아 저장소를 받아 오고 은하로 들인다 |
| **은하** | 우주가 아는 은하 명부 — 등재된 것과 좌표만 있는 것 |
| **위반** | 법칙 위반 목록과 처방 |
| **주행** | 주행 결과 — ⛔ 끝나는 조건은 「fail 0」이 아니라 **「판단하지 않은 fail 0」** |
| **TC** | 양식을 내려받고 · 채운 것을 올려 돌리고 · 보면서 돌린다 |
| **잴 저장소** | 로컬 폴더를 읽어 **좌표 초안**을 만든다 |

## 띄우기

```bash
cd app/universe
npm install          # 최초 1회
npm run dev          # 화면 http://127.0.0.1:5174 · 서버 http://127.0.0.1:8788
```

> 루트 저장소의 관문은 이 앱의 `node_modules` 를 받지 않는다. **관문 시간에 영향이 없다.**

⚠️ 서버는 **127.0.0.1 에만** 바인딩한다. 이건 로컬 도구다.

`UNIVERSE_ROOT` 로 다른 우주 체크아웃에 붙일 수 있다(기본은 이 앱이 사는 저장소):

```bash
UNIVERSE_ROOT=../다른-우주 npm run dev
```

## ⛔ 형제 저장소를 끊었다

전에는 이 콘솔의 라우트 **13개**(`/api/domains/**`)가 **형제 폴더의 남의 저장소**
(`qa-workflow-v2-main`)를 지식 출처로 삼았고, 한때는 그것이 **첫 화면**이었다 —
우주가 아는 은하가 화면에 아예 안 뜨는 동안 남의 저장소의 「도메인」이 떠 있었다.

지운 것: `domains.ts` · `survey.ts` · `collect.ts` · `emit.ts` · `provenance.ts` ·
라우트 13개 · 화면 `Survey` · `DomainSelect` 의 도메인 목록 절 · 타입 9종과 라벨 3벌.

⚠️ **함께 잃은 것도 적어 둔다** — 안 적으면 「원래 없었다」와 구별이 안 된다:

- **로그인 세션을 여는 자리가 없어졌다.** 세션은 도메인 설문에서 URL·계정을 받아 열렸다.
  ⇒ 전제 `session-alive` 는 은하가 `requiresSession: true` 를 **선언했을 때 ⚪(못 쟀다)** 다.
  ⛔ `ok:true` 로 두지 않았다 — 그러면 로그인이 필요한 은하가 **조용히 통과**한다.
  (선언한 은하는 지금 **0개**라, 이 ⚪ 는 배경 소음이 되지 않고 선언하는 날 바로 보인다.)
- **도메인 지식 문서를 생성하던 길**(`emit`)이 통째로 없다. 그건 이 우주의 일이 아니었다.

## 이 콘솔이 지키는 것

- ⛔ **화면은 관문을 못 끈다.** 「무시하고 계속」·「전부 통과 처리」 갈래가 어디에도 없다.
- ⛔ **못 쟀다(⚪)를 통과(✅)로 접지 않는다.** 판정 어휘는 셋이고 색도 넷이다.
- ⛔ **화면이 판정을 지어내지 않는다.** 판정은 계약 도구가 내고 화면은 나른다.
- **초안은 커밋되지 않는다** — `.data/` 는 gitignore 된다.
- **사람이 누른 것은 주장이지 측정이 아니다.** 누가·언제 판정했는지를 **서버가** 찍는다.

## 화면의 색 — 라이트가 기본이다

`index.html` 의 `data-theme="light"` 한 글자가 테마다. **지우면 다크로 돌아간다.**
두 벌 모두 **WCAG 상대휘도 대비를 계산해서** 골랐다 — 값의 출처와 실측표는
`web/src/styles/tokens/_palette.css`(다크)와 `_themes.css`(라이트) 머리말에 있다.
⛔ 「예뻐 보이니까」로 바꾼 값은 한 칸도 없다.
